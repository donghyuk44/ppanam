# 떠 있는 세라 — 창 설계 1판 (솔라에게)

> **09-14 아침 고침 (대표 지적 — "Kenney 로 승인한 거랑 반대").** 4절의 손그림 SVG 세라(`out/screens/sera-float.svg` 의 `<g id="sera">`)는 **접는다** — 결정 55·57 은 Kenney 인형을 코드로 고쳐 쓰는 것이고, 손으로 그린 캐릭터는 그 밖이다. 세라 실물 = Kenney `character-female-b.glb` + 색표 `out/kit/colormaps/people/hq-secretary.png` + 리본(characters.json prop) 을 **Three.js 로 200px 정면에서 찍은 PNG**(투명 배경, 개발이 첫 화면과 같은 빛·재질로). 생성 그림 요청 `sera-float.json` 도 같은 이유로 접는다 — 시안이 아니라 렌더가 그림이다. 창 치수·자리·상태(1~3절)와 SVG 의 막대·아이콘(`<g id="pill">`, 벡터 UI)은 그대로 쓴다.

2026-09-14 새벽 · 헨리. 대표 결정 87(맥 화면 위에 늘 떠 있는 비서)·86(세라 26, 일본). 솔라가 Tauri 로 창을 짜고, 이 문서가 그 창 안에 무엇이 어디 놓이는지다. 그림은 둘: **`out/screens/sera-float.svg`**(도형으로 그린 시안 — 생성 통로가 닫혀 먼저 그림) · `out/gpt/requests/sera-float.json`(생성 그림 요청, 통로 열리면 뽑힘 — 그게 오면 SVG 세라를 그 그림으로 바꾼다, 치수는 같다).
세라 모습은 `out/kit/characters.json` hq-secretary 와 같다 — 물색 상의 #5f8fbf · 흰 아래 · 검은 땋은 머리 · 붉은 리본 #c94a3a · 살 #f3d3b3. 마을 인형과 같은 사람으로 읽혀야 한다.

## 1. 창 — 치수

| 것 | 값 | 왜 |
| --- | --- | --- |
| 창 크기 | **300 × 300** (논리 px, 레티나면 ×2) | 세라 200 + 막대 48 + 여백. 말풍선은 창 안에서 위로 편다 |
| 바탕 | 투명. 창 테두리·그림자 없음 | 캐릭터만 떠 있어야 한다(대표 참고 그림) |
| 자리 | 처음은 화면 **오른쪽 아래**, 가장자리에서 24. 끌어 옮길 수 있고 자리를 기억한다 | 알림 배지가 있는 창은 눈 가는 구석에 |
| 늘 위 | 예(always on top). 전체 화면 앱 위에서는 숨는다 | 떠 있으라는 게 원문 |
| 클릭 통과 | 세라 몸·막대 밖(투명 부분)은 **클릭이 뒤 창으로 간다** | 안 그러면 300×300 이 화면을 가린다 |

## 2. 안에 놓이는 것 — 좌표는 창 왼쪽 위 (0,0)

| 것 | 자리 · 크기 | 상태 |
| --- | --- | --- |
| **세라** | 발밑선 y=240, 가운데 x=150, 키 **200**(머리 위 y≈40). 폭 약 100 | 가만히: 2초에 한 번 살짝 숨 쉬듯 위아래 2px. 눌리면(hover) 눈이 창 쪽을 본다 — 없어도 됨 |
| **막대** | 220 × 48, 알약(라운드 24), x 40~260 · y 246~294. 바탕 #f4efe4, 테두리 #d9d1bf 1px | 세라 발밑 그림자가 막대 위에만 진다 |
| 아이콘 ① 고치기(렌치) | 막대 안 x=90, 24px | 누르면 설정(자리 초기화 · 소리 켜고 끄기 · 종료) |
| 아이콘 ② 소리(스피커) | x=150 | 누르면 소리 켬/끔 — 끄면 스피커에 빗금 |
| 아이콘 ③ 알림(종) + 배지 | x=210. 배지: 지름 14, #c94a3a, 흰 숫자, 종 오른쪽 위 | 대표가 안 본 것 수. 0 이면 배지 없음. 누르면 말풍선에 첫 항목 |
| **말풍선** | 세라 머리 오른쪽 위. 왼쪽 아래 귀가 입을 가리킨다. 최대 폭 **150**, 글자 12px, **두 줄까지** | 세라 말은 한두 문장(결정 98 — 대표에게 가는 말만, 세라가 추린 것). 나타날 때 0.2초 페이드, 8초 뒤 사라짐. 누르면 관제탑의 그 항목으로 |

세라 몸은 창 안에서 x 100~200 · y 40~240 을 쓴다. 이 밖은 전부 투명(클릭 통과).

## 3. 상태 — 넷뿐

| 상태 | 세라 | 막대 | 말풍선 |
| --- | --- | --- | --- |
| 가만히 | 숨 쉬기 | 배지 없음 | 없음 |
| 알림 있음 | 가만히 + 한 번 폴짝(4px) | 배지 숫자 | 없음 — 대표가 종을 누르면 |
| 말하는 중 | 눈이 말풍선 쪽 | 그대로 | 있음 (두 줄) |
| 아침 첫 인사 | 손 흔들기 없음 — 그림 한 장이라 | 배지 | "좋은 아침이에요. 밤새 N 가지가 올라왔어요." — 글은 하영·세라 인격 |

넷 넘게 만들지 않는다. 걷기·표정 여러 장은 첫 판 밖.

## 4. 그림 파일 — 솔라가 받는 것

- 지금: `out/screens/sera-float.svg` — 안에 `<g id="sera">`(세라, 발밑 원점 (0,196) 기준 200 키)와 `<g id="pill">`(막대, 가운데 위 원점)이 따로 있어 그대로 꺼내 쓴다. SVG 라 레티나에서도 깨끗하다.
- 나중: 생성 그림이 오면 `out/screens/sera-float-alpha.png`(자홍 제거) 에서 세라만 잘라 같은 치수(키 200)로 바꾼다. 막대·아이콘은 SVG 그대로 — 그림에 안 넣는다(글자·아이콘은 벡터가 낫다).
- 200px 검사(마크): 리본이 머리 윤곽 밖에 남나 — SVG 세라는 리본이 땋은 머리 끝 왼쪽 밖으로 18px 나와 있다.

## 5. 안 하는 것

- 세라와 대화창(입력) — 첫 판은 보기·누르기까지. 말 걸기는 관제탑에서.
- 여러 표정·걷기 — 그림 한 장.
- 소리 파일 — 켜고 끄는 자리만 둔다.
