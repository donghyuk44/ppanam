# 얼굴 썸네일 열일곱 — 규격 1판

2026-09-16 R17 헨리. 6단계(대표 원문 129·131 — "각자 원하는 얼굴을 만들어서 넣어줘" · "썸네일 일러스트로 가자"). 로드맵 카드 apr_8e62ce66 통과 전이라 재료만 먼저(나리 결정).

## 1. 무엇 하나

마을 인형과 같은 얼굴. 그리지 않는다 — `out/kit/characters.json` 의 인형을 정면 200px 로 **찍는다**. 세라 한 장(`out/screens/sera-200.png`, 개발 R25)과 같은 방법.

    node tools/lineup-shot.mjs teams/design/out/faces/<자리>.png "only=<자리>&size=200&transparent=1&front=1&head=1" 200 200

- 파일: `out/faces/<자리>.png` 열일곱 · 200×200 · 투명 배경 · 정면
- `<자리>` 는 characters.json 의 키 그대로(boss(댄) · hq-chief · … · hq-secretary). 나리는 새 키 — 2절
- 서버(localhost:4321)가 떠 있어야 찍힌다. 안 뜨면 개발에 요청 블록
- manifest: `out/faces/manifest.json` 에 자리 · 파일 · 명령 · 찍은 날 · 한 줄(3절)

**`head=1` — 머리를 잡는 값(1판 뒤 더함, 09-16).** 나리가 1판 열다섯을 찍어 보니 `lineup.html` 은 `only` 하나짜리도 전신을 잡는다(lineup.js 카메라 — 팔 벌린 폭 기준). 얼굴이 200px 중 60px, 채팅 아바타 32px 로 줄이면 얼굴이 10px — 그건 얼굴이 아니라 인형 사진이다. `head=1` 은 없는 값이라 개발 손(요청 블록): **카메라가 머리를 잡는다 — 위는 머리 꼭대기(갓·리본까지) 위 여백 조금, 아래는 어깨선, 좌우는 어깨 폭. 정면(`front=1`). 얼굴(살색 면)이 200px 중 120px 이상.** 같은 값이면 열일곱이 같은 크기의 얼굴로 나온다 — 자리마다 키가 달라도 머리 크기는 Kenney 몸이 거의 같다.

1판(전신, 02:16~02:17)은 `head=1` 이 오면 다시 찍는다 — 한 장에 명령 하나.

마크가 세는 것: 파일 열일곱 존재 · 전부 200×200 · manifest 의 명령이 위와 같다 · 얼굴 색이 characters.json 색과 같다(옷·머리·살) · 얼굴이 200px 중 120px 이상(머리 잡기).

## 2. 나리 — 열일곱째 자리

characters.json 은 열여섯이다. 나리 한 자리를 더한다 — 몸 파일 · 배율 1.39 · 옷 위아래·머리·살 색(32색 안) · 부착물 · 실루엣 근거 · 색표 한 장(`out/kit/colormaps/people/`). 몸 열둘은 다 쓰였으므로 **같은 몸 + 다른 부착물**로 가른다(규칙: 색만 다른 둘은 없다). 키 이름은 서버 캐스트와 같아야 하므로 테라와 맞춘다 — 헨리가 묻는다.

## 4. 위험 하나

얼굴은 지금 인형(characters.json) 기준이다. 대표님이 아침에 마을 방향을 되돌리시면 열일곱 다시 찍는다 — 찍는 데 한 장에 명령 하나라 다시 찍는 값은 작다. 그래서 그림을 손으로 안 그린다.
