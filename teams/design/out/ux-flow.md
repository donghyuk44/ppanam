# UX 흐름 · 장면별 우선순위 — 클레멘타인

2026-09-13 · 대표 결정 43. 관제탑·방·마을 세 장면마다 "대표가 30초 안에 봐야 할 것 셋"과 화면 사이 이동을 적는다.
근거는 코드와 이미 쓴 문서다 — `server/public/index.html`·`style.css`·`app.js`, `teams/design/out/opsroom-tower-tabs.md`, `teams/design/out/direction.md` 8절. 새로 지어내지 않았다.

## 0. 흐름 지도 — 어디서 어디로

```
관제탑(팀 카드) ──누르면──▶ 방(그 팀 작전실)
관제탑(개인 카드 칩) ──누르면──▶ 개인 탭의 그 카드로 스크롤(관제탑 안에서만)
종 배지(대표 차례 n) ──누르면──▶ 승인 카드 있으면 관제탑 / 없으면 그 방
마을(캐릭터) ──누르면──▶ 카드(누구·지금·일지·최근 발언 여덟)
마을 카드(발언 하나) ──누르면──▶ 방의 그 발언(점프해 잠깐 빛남)
방(디자인) ──"마을" 탭──▶ 마을의 `home.design.guide`(x24,y23) 자리로 카메라 이동
관제탑·분석 ⇄ 방·마을 ──왼쪽 레일 4탭 버튼으로 전환
```

**방 → 마을 확정(마크 지적, R13):** 이동 수단은 새로 안 만든다 — 왼쪽 레일 "마을" 탭 그대로. 다만 지금 보던 팀을 들고 간다: `setView('world')` 가 `active` 팀 id 를 `World.open`에 같이 넘기고, 세계는 `world/map.json` 의 `places["home.<team>.guide"]`(마을 씬 기본, 예: 디자인이면 `home.design.guide` = x24,y23) 혹은 회사(castle) 씬이 열려 있으면 `<team>.desk.guide` 로 카메라를 이동시킨다. 좌표는 이미 map.json 에 다 있어서(마케팅·개발·디자인·경영재무·총괄 다섯 다) 새 데이터가 필요 없다 — 서버가 아니라 `app.js`/`world.js` 둘의 연결만 빠져 있다(`World.open({teams, jump})` 에 `focus` 인자 하나 추가).

**지도 y → 세계 z 변환(마크, 이어서):** `teams/design/out/village-file-contract.md` "축" 절에 이미 정해져 있다 — `x=동(+)·z=남(+)·y=위(+)`, **지도 (x, y) → three.js (x, 0, y)**, 뒤집지 않는다. 세계 단위 = 지도 한 칸(1:1)이라 배율 곱셈도 없다. 그러니 `home.design.guide {x:24, y:23}` 은 그대로 `three.js (24, 0, 23)` 이 카메라 목표점이다 — `focus` 인자에 넘길 값은 `{x: place.x, y: 0, z: place.y}`. 새 계약이 아니라 이미 있는 계약을 그대로 쓰는 것뿐이라 개발팀에 다시 물을 필요는 없다.

## 1. 관제탑 — 30초 안에 볼 것 셋

`opsroom-tower-tabs.md` 2·3절의 줄 순서가 이미 그 "셋"이다. 새로 고르지 않고 그대로 끌어왔다.

**팀 탭**
1. 상태 알약(대표 차례 / 막힘 / 진행 중 / 대기) — 다섯 카드 중 어디부터 봐야 하는지, 한눈에
2. 숫자 줄 — `대표 차례 n · 승인 대기 n · 작업 중 누구`. 0 이면 항목 자체가 없어서 있는 것만 눈에 걸린다
3. 진행 막대 + 분수(`1/4`) — 마일스톤 어디까지 왔는지

**개인 탭**
1. 대표 카드(맨 위 고정) — 내 상태(자리에/자리 비움)
2. 대표 부름 줄(4줄) — 있는 사람만 보인다, 없으면 그 줄 자체가 없어서 "아무도 안 불렀다"가 바로 읽힌다
3. 알약 색 분포(일하는 중=live·대표 부름=bad·잠=ink-4) — 훑으면 지금 회사 전체가 도는지 자는지 감이 온다

## 2. 방(작전실) — 30초 안에 볼 것 셋

`index.html` 구조 순서(위→아래) 그대로: `approvals` → `roundbar` → `stream`(발언·도구·**도장**) → `composer`.

1. 라운드 줄(`roundbar`) — `R13`·마일스톤 제목·진행(`rprog`)·지금 일하는 사람(`rwork`). 방을 열자마자 첫 줄
2. 판정 도장(`.stamp`) — 마지막 PASS·REVISE·FAIL 이 스트림에서 제일 큰 시각 요소(2px 테두리, 색 두 벌뿐)라 스크롤 중에도 걸린다
3. 대표를 부른 말풍선(`.row.calls-boss`, 왼쪽 안쪽 `--bad` 띠) — 이게 없으면 그냥 지나칠 수 있는 한 줄이라 셋에 넣었다

## 3. 마을 — 30초 안에 볼 것 셋

`direction.md` 8절 "ZEP 넷" 중 화면에 남는 것 셋(참가자 목록은 관제탑 개인 탭으로 갔다, opsroom-tower-tabs.md 0절).

1. 이름표(머리 위 두 줄 — 상태 + 이름) — 누가 어디서 뭘 하는지, 캐릭터를 누르기 전에도 보인다
2. 포탈 간판(문 위, `GUIDE`·`MAP` 자리) — 어디로 이동할 수 있는지
3. 세상의 시계(`#wvClock`, `state/world.json`) — 지금이 근무 시간인지 밤인지. 이게 있어야 "다들 자고 있다"가 이상한 게 아니라 정상으로 읽힌다

## 안 다룬 것

- 분석 탭 — 결정 43 이 관제탑·방·마을 셋만 짚었다. 분석은 대표가 "깊게 볼 때" 쓰는 화면이라 30초 훑기 대상이 아니다.
