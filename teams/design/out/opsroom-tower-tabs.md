## 1. 탭 줄

관제탑 머리(`.tower__head`, 제목 "관제탑" Gowun Batang 19px) 바로 밑, 카드 격자 위.

- 버튼 둘 `팀` · `개인`. 지금 `.views button` 과 같은 모양(11.5px → **12.5px**, 라운드 7, 선택된 것은 `--panel` 바탕 + `--line` 테두리 + 굵기 500). **높이 36px** 이상 — 폰 손가락.
- 각 버튼 오른쪽에 작은 숫자: `팀` 은 대표 차례인 팀 수, `개인` 은 대표를 부른 사람 수. 0 이면 숫자 없음. 숫자는 `--bad` 색 mono 10.5px — 오른쪽 위 종 배지(결정 34)와 같은 값의 조각이라 색도 같다.
- 마지막에 본 탭을 기억한다(`localStorage`). 처음은 `팀`.
- 폰에서 탭 줄은 **위에 붙는다**(sticky) — 열다섯 카드를 내리다 탭을 바꾸러 올라오지 않게.

## 2. 팀 탭 — 다섯 카드

지금 `.tcard` 를 다시 묶는다. 없는 걸 만드는 게 아니라 **줄 순서를 고정**하는 것이다. 대표가 30초 안에 읽는 순서 = 위에서 아래.

```
┌──────────────────────────────────────────────┐
│ 디자인                          [대표 차례]  │  1줄 이름 + 상태 알약
│ R13 · 마일스톤 1 아트 디렉션과 건물 키트 컨셉  │  2줄 라운드·단계
│ ▓▓▓░░░░  1/4                                 │  3줄 진행 막대 + 분수
│ 대표 차례 1 · 승인 대기 2 · 작업 중 헨리      │  4줄 숫자 줄 (0 은 숨김)
│ ● 헨리  ● 클레멘타인  ● 마크                  │  5줄 팀원 칩 (일하는 사람은 점이 산다)
│ 헨리 · 마지막 말 한 줄… · 3분 전              │  6줄 마지막 발언 (지금 그대로)
└──────────────────────────────────────────────┘
```

| 줄 | 무엇 | 글자 | 규칙 |
| --- | --- | --- | --- |
| 1 | 팀 이름 | Gowun Batang **16px** (`.card__big`) | 누르면 그 작전실로(지금 동작 그대로) |
| 1 | 상태 알약 (오른쪽) | mono 9.5px, 자간 .13em, 라운드 4, 패딩 1×6 | `대표 차례`(--bad 바탕·--bad-bg 글자) · `진행 중`(--live 테두리·글자) · `막힘`(--bad 테두리) · `대기`(--line 테두리·--ink-4) · `1:1`(총괄실) |
| 2 | 라운드·마일스톤 | 12.5px --ink-2, `R13` 만 굵게 500 | 한 줄, 넘치면 … |
| 3 | 진행 막대 `.bar2` + `1/4` | 막대 높이 5px, 분수 mono 10.5px --ink-4 | 지금 `마일스톤 1/4` 글자를 분수로 줄인다 |
| 4 | 숫자 줄 | 12px, 항목 사이 ` · ` | `대표 차례 n`(--bad, 굵게) · `승인 대기 n`(--me-line 글자) · `작업 중 이름·이름`(--live) · `반박 n/3`(게이지 `.gauge` 대신 글자 — 폰에서 5px 점 셋은 안 보인다). **0 이면 항목 자체가 없다** (네이버 내 카드 방식) |
| 5 | 팀원 칩 | 칩 22px 원(자리 색, 이니셜 mono 10px) + 이름 12px | 일하는 사람은 칩 오른쪽 아래에 **--live 점 6px**, 대표를 부른 사람은 **--bad 점**. 칩을 누르면 개인 탭의 그 카드로 |
| 6 | 마지막 발언 | 지금 `.tcard__last` 그대로 (세 줄 자름) | 도구 줄(`.tcard__tool`)은 4줄 `작업 중` 에 합쳐져서 따로 안 둔다 |

- 카드 순서는 **늘 같다** — 총괄 · 마케팅 · 개발 · 디자인 · 재무(`state/teams.json` 순서). 대표 차례라고 위로 올리지 않는다. 자리를 외우게 하는 게 빠르다. 대신 대표 차례 카드는 **왼쪽 안쪽 3px --bad 띠**(`.row.calls-boss .bub` 와 같은 표시).
- 상황(`.tcard__prog` details) 은 그대로 6줄 밑에 접힌 채로.

## 3. 개인 탭 — 열다섯 카드

```
┌──────────────────────────────────────────────┐
│ [댄]  함동혁 · 대표                  [자리에]│  대표 카드 — 맨 위 고정, 묶음 밖
└──────────────────────────────────────────────┘
디자인 3 ─────────────────────────────── ▾       묶음 머리 (접기)
┌──────────────────────────────────────────────┐
│ [헨]  헨리 · 메인 디자인          [일하는 중]│  1줄 칩 + 이름 · 자리 + 상태 알약
│ direction.md 3절 카메라 고치는 중            │  2줄 지금 하는 일
│ 신호 2분 전 · 오늘 발언 14 · 판정 0           │  3줄 숫자 줄
│ 대표 불렀음 · 12분 전 · "손 하나 빌리겠…"     │  4줄 대표 부름 (없으면 줄 없음)
│ 「나는 헨리, 예쁜 그림보다 구도를 먼저…」      │  5줄 일지 첫 문장
└──────────────────────────────────────────────┘
```

| 줄 | 무엇 | 글자 | 규칙 |
| --- | --- | --- | --- |
| 1 | 칩 | 26px 원, 자리 색(`cast.json`), 이니셜 mono 11px | 지금 `.chip` 과 같은 것, 한 단계 크게 |
| 1 | 이름 · 자리 | 이름 **13.5px 500** --ink · 자리 11px --ink-4 | `헨리 · 메인 디자인`. 자리 이름은 `cast.json` role |
| 1 | 상태 알약 (오른쪽) | 2절과 같은 알약 | `일하는 중`(--live) · `대표 부름`(--bad 바탕) · `막힘`(--bad 테두리) · `대기`(--ink-4) · `잠`(--ink-4, 밤·주말 — `world.mjs` 시계) |
| 2 | 지금 하는 일 | 12.5px --ink-2, **두 줄** 자름 | 마지막 도구 줄의 `toolPhrase`(지금 `.tcard__tool` 문장) 또는 마지막 발언 첫 문장. 없으면 `—` |
| 3 | 숫자 줄 | mono 10.5px --ink-4, ` · ` 구분 | `신호 2분 전`(마지막 신호, `sessions[id].lastSignal`) · `오늘 발언 14` · `판정 0`(감사 자리만 — 실무·운영은 이 항목 없음) |
| 4 | 대표 부름 | 12px --bad | `대표 불렀음 · 12분 전 · "첫 열두 자…"`. **불렀는데 대표가 아직 답 안 했을 때만** 줄이 생긴다. 답했으면 사라진다 |
| 5 | 일지 첫 문장 | Gowun Batang **12.5px** --ink-3, 「」 안에, 한 줄 자름 | `teams/<팀>/journal/<자리>.md` 최근 문단 첫 문장("나는 …"). 누르면 문단 전체 펼침. 일지가 없으면 줄 없음 |

- **대표 카드** — 맨 위, 묶음 밖, 테두리 `--me-line`(대표 말풍선 색). 알약은 `자리에`(마을 좌표가 대표 집무실이거나 마지막 발언 10분 안) / `자리 비움`. 2줄은 대표의 마지막 지시 첫 문장, 3줄은 `오늘 지시 n · 결정 n`. 4·5줄 없음.
- **묶음** — 팀별 `details/summary`. 머리 `디자인 3` 은 mono 9.5px 자간 .13em --ink-4(`.card__k` 와 같음) + 오른쪽 접기 표시. 묶음 안에 대표를 부른 사람이 있으면 머리 오른쪽에 `--bad` 점. 처음엔 전부 펼침. 접힘은 기억(`localStorage`).
- 묶음 순서·묶음 안 순서는 `teams.json`·`cast.json` 순서 — 마을의 책상 순서와 같다(바이블 2절). 여기서도 자리를 외운다.
- 카드 순서를 상태로 바꾸지 않는다. **정렬 버튼 없음.** 열다섯이라 한 번 훑는 게 정렬보다 빠르다.

## 4. 격자 — 데스크톱과 폰

| 폭 | 팀 탭 | 개인 탭 |
| --- | --- | --- |
| ≥ 1200 (레일 224 + 본문) | `repeat(auto-fill, minmax(330px, 1fr))` 지금 그대로 → 본문 1216 에서 **3열**, 다섯 카드가 두 줄 | 대표 카드 한 줄 전체 폭. 묶음마다 `repeat(auto-fill, minmax(300px, 1fr))` → **3열**, 팀 셋이 한 줄. 묶음 머리는 열 전체 |
| 768~1199 (레일 210) | 2열 | 2열 |
| < 768 (폰) | **1열**, 패딩 12, 카드 사이 10 (`.tower__grid` 폰 규칙 그대로) | 1열. 묶음 머리 **위에 붙음**(sticky, 탭 줄 밑) |

- 폰 412: 카드 안 폭 412 − 12·2(패딩) − 14·2(카드 패딩) = **360px**. 1줄에 칩 26 + 이름·자리 + 알약(최대 64px) 이 들어간다 — 이름·자리는 `min-width: 0; text-overflow: ellipsis`.
- 카드 높이는 내용대로. 개인 카드 다섯 줄 다 있으면 약 150px → 폰 세로 915 에 다섯 장쯤. 열다섯이면 세 화면 — 그래서 묶음 접기가 있다.
- 두 탭 모두 격자 위 `승인 대기` 블록(`.approvals`)은 **지금 자리 그대로** 둔다(결정 20). 탭을 바꿔도 안 사라진다.

## 6. 색 규칙

- 상태 다섯 = 색 셋. **--bad**(대표 차례·대표 부름·막힘) · **--live**(일하는 중·진행 중) · **--ink-4**(대기·잠·1:1). 노란 `--me-line` 은 승인 대기와 대표 카드 테두리에만. 그 밖의 색은 자리 색 칩뿐.
- 다크 모드는 토큰이 알아서 바꾼다. 새 색 없음.
- 팔레트(`out/palette.json` 32색)는 **마을 그림**의 것이다. 작전실 UI 는 `style.css` 토큰 — 섞지 않는다.

## 7. 서버가 줘야 하는 값 (개발팀 몫 — 지금 `teamSummary` 에 없는 것)

개인 탭 열다섯 카드에 쓰는 값 중 지금 요약에 없는 것. 이름은 제안이다.

클레멘타인이 코드를 열어 본 것(09-13)을 반영했다.

- `people[id].todaySay` · `todayVerdict` — 오늘(마을 시계 날짜) 발언 수·판정 수. **새 값.**
- `people[id].bossCall` — `{ ts, text }`. 지금은 팀 단위 `bossCall: { by, ts }` 만 있고 **인용문 `text` 가 없다**(`app.js` 210·1052행). 3절 4줄의 `"손 하나 빌리겠…"` 은 서버가 `text`(첫 열두 자)를 줘야 나온다 — **`bossCall.text` 추가**. 사람 단위로 옮기거나, 팀 단위를 두고 `by` 로 카드에 붙여도 된다. 대표가 답하면 null.
- `people[id].journalFirst` — 일지 최근 문단 첫 문장. 새 값이 아니다 — `session.journalOf(team, actor, 1)` 이 캐릭터 카드용으로 있다. **열다섯 번 따로 부르지 말고 팀 요약(`teamSummary`)에 접어서** 한 번에 준다.
- `people[id].doing` — `lastTool` 문장(`toolPhrase`) 또는 마지막 발언 첫 문장(서버가 골라 준다). 새 값.
- 대표: `boss.lastOrder` · `boss.todayOrders` · `boss.todayDecisions`. 새 값.
- **있는 값 그대로** — `sessions[id].busy`·`lastSignal` 은 자리별로 진짜 있다(`session.statusAll`, `server/session.mjs` 477행). `needsBoss`, `approvals.pending`, `round`·`milestone*`, `attempt` 도 그대로.

## 8. 비어 있을 때

## 그림 — 나온 것 (09-13, `out/screens/tower-tabs.png` 1725×912, 헨리가 열어 봄)
