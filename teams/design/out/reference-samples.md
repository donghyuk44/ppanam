# 참고 화면 샘플 — 네이버 · 레딧 · ZEP

2026-09-13 · 대표 결정 34(`teams/dev/decisions.md`)의 "가져올 것"을 바탕으로 만든 비교 샘플. 보조 세션이 찍고 썼다.
QA 는 네이버·레딧을 **비교 샘플**로, 디자인팀은 ZEP 을 **마을 움직임 참고**로 본다. 팀 세션은 브라우저가 없으니 아래 PNG 를 Read 로 열어 본다.

두 종류를 섞지 않는다. **찍힌 것**은 PNG 를 열어 실제로 본 것이다. **대표 스크린샷 기준**은 결정 34 에 적힌 대표 화면(로그인 상태)의 값이고, 이번 캡처에는 안 나온다. **공개된 사용법 기준(직접 확인 못 함)**은 정지 화면으로는 볼 수 없어 사용법 지식으로만 적은 것이다.

## 2. 네이버 홈에서 배울 것

찍힌 것(`naver-desktop.png`, 로그아웃):

- **상단 검색** — 화면 가운데 한 줄, 왼쪽 로고·오른쪽 키보드 아이콘과 "AI" 버튼. 검색이 첫 시선이다.
- **서비스 아이콘 줄** — 검색 바로 아래 한 줄 열 개: 메일 · 카페 · 블로그 · 쇼핑 · 뉴스 · 증권 · 부동산 · 지도 · 웹툰 · 치지직 · 더보기(…). 아이콘 위, 이름 아래.
- **오른쪽 위** — 종 아이콘과 장바구니. 이번 캡처는 로그아웃이라 **배지가 없다.** 자리만 확인됐다.
- **오른쪽 열 첫 카드** — 로그아웃이라 **로그인 카드**("네이버를 더 안전하고 편리하게 이용하세요" · NAVER 로그인 · 아이디 찾기 | 비밀번호 찾기 | 회원가입)가 대표 화면의 "내 카드" 자리를 차지한다. 즉 **내 카드는 첫 화면 오른쪽 위, 접히지 않는 고정 자리**다.
- **뉴스·쇼핑 카드 격자** — 뉴스스탠드는 언론사 로고 6열 4행 격자, 아래 쇼핑 탭 줄(맨즈 · 브랜드샵 · 지금뜨는 · 혜택 · 추천핫딜 · 쇼핑라이브, 1/10 페이지).
- **광고 표시** — 오른쪽 아파트 광고 카드 오른쪽 위에 작은 **"AD"** 꼬리표. 광고와 콘텐츠를 같은 카드 모양으로 두되 꼬리표로 구분한다.

찍힌 것(`naver-mobile.png`, 모바일판):

- 위에 햄버거·pay, 검색창(N 로고·렌즈 아이콘), 광고 띠, 서비스 줄이 **아이콘 셋(메일·카페·쇼핑) + 글자 탭(뉴스·엔터·스포츠·쇼핑)** 으로 줄어든다.
- 날씨(26.2° 청주)·코스피 한 줄 뒤 **두 열 카드 피드** — 카드마다 작성자 아바타+이름(인증 체크 포함)·큰 그림·제목 두 줄.
- 폰 폭에서 종 아이콘이 상단에 **안 보인다.** 검색창과 "AI탭에서" 칩이 오른쪽으로 넘친다(가로 넘침 사례로 QA 가 볼 것).

대표 스크린샷 기준(결정 34, 이번 캡처에는 없음): 종에 **"99+" 빨간 배지**, 내 카드에 **이름·아이디·멤버십**과 **"메일 99+ · 카페 99+ · 블로그 2"** 서비스별 미확인 수, 로그인한 내가 항상 보임.

우리 작전실에 대응시키면:

| 네이버 | 작전실 |
| --- | --- |
| 오른쪽 위 종 + 99+ 배지 | 모든 탭 오른쪽 위 종 = **대표 차례 수** |
| 내 카드(이름·아이디·멤버십·서비스별 미확인 수) | **대표 카드** — 할 일 N · 승인 대기 N, 첫 화면 오른쪽 위 고정 |
| 서비스 아이콘 줄(메일 · 카페 · 블로그 …) | **방 목록** — 방마다 아이콘 + 이름 + 미확인 수 |
| 뉴스·쇼핑 카드 격자 | 관제탑의 라운드·산출물 카드 |
| AD 꼬리표 | 환경 화자·시스템 발언 꼬리표(사람 발언과 같은 카드, 다른 꼬리표) |

## 3. 레딧 홈에서 배울 것

찍힌 것(`reddit-mobile.png`, 로그아웃, 어두운 테마):

- **글 카드 하나 = 한 항목.** 위에서 아래로 — 커뮤니티 아바타 + `r/mildlyinfuriating` · `2시간 전` → 제목(굵게, 두 줄) → 본문 미리보기(회색, 세 줄) → 반응 줄(↑ `1.9천` ↓ · 💬 `303` · 공유). 누가·언제·무엇·반응이 카드 안에서 위→아래 순서로 한 번에 읽힌다.
- **광고도 같은 카드** — `u/RevenueCat · 광고` 꼬리표 뒤 제목·큰 그림. 네이버의 AD 와 같은 방식.
- 카드 위 **정렬 줄** — "좋아요 비율 높은 순 ▾ · 전 세계 ▾ · 보기 방식". 피드 위에 정렬·필터가 한 줄.
- 어두운 테마 대비 — 검은 바탕에 흰 제목, 회색 본문, 반응 알약은 짙은 회색 배경.
- 폰 폭에서 오른쪽이 넘친다(주황 "앱" 버튼 잘림, 본문 오른쪽 끝 잘림). QA 눈금 ⑤ 의 **나쁜 예**로 같이 본다.

찍힌 것(`reddit-desktop.png`): **봇 차단 벽.** 왼쪽 세로 메뉴·종·만들기·아바타는 이번 캡처로 확인 못 했다.

대표 스크린샷 기준(결정 34): 왼쪽 세로 메뉴(홈 · 인기 · 소식 · 탐색, 접히는 묶음), 오른쪽 위 **종 배지 "1"** + 만들기 + 아바타, 글 카드에 `19 hr. ago` · 반응 33 · 댓글 25 · 공유.

우리 작전실에 대응시키면:

| 레딧 | 작전실 |
| --- | --- |
| 글 카드(누가·언제·제목·그림·반응·댓글·공유) | **발언 카드** — 누가(팀 색 아바타·이름) · 언제 · 무엇 · **판정 도장** · 댓글 수 |
| 왼쪽 세로 메뉴(홈·인기·소식·탐색) | **왼쪽 메뉴 = 방 목록 + 관제탑 + 마을**, 묶음은 접힘 |
| 종 배지 "1" | 대표 차례 수 (네이버와 같은 자리) |
| 정렬 줄 | 라운드 선택·판정만 보기 필터 |
| 어두운 테마 | 작전실 기본 테마 대비 기준 |

## 4. ZEP(가상 사무실)에서 배울 것

찍힌 것(`zep-desktop.png`, 게스트 입장 — 로그인 벽 없이 바로 들어감):

- **아바타가 맵 안에 서 있고 이름표가 머리 위.** 두 줄 — 위에 상태 `🏠 재택`, 아래에 이름 `🍀🍀🍀 공룡/게스트/게스트/게스트`. 이름표는 아바타보다 넓고 항상 켜져 있다.
- **피플 목록 패널**("ZEP 피플 목록") — 맨 위 `나` 줄에 상태 드롭다운(`🏠 재택 ▾`)과 **`내 자리 →`** 버튼, 구성원 검색창, 묶음 `게스트 1/1` 접기, 각 사람 줄에 이름 + 상태 알약. 사람마다 한 줄, 상태가 같이 붙는다.
- **오른쪽 위** — 종 아이콘 · 참가자 아이콘 + 숫자 `1` · **초대하기** 버튼. 작전실 종 자리와 같다.
- **포탈** — 맵 위에 `GUIDE` · `MAP` 이라 적힌 문 모양 타일 둘. 방(공간) 이동 입구가 맵 안의 물건으로 보인다.
- **아래 줄** — 반응 이모지 알약(👍 👏 ❤️ 😆 😂 + 이모지 고르기), 오른쪽 아래 **메시지** 버튼, 왼쪽 아래 채팅 입력줄(이번 캡처에서는 피플 목록 패널에 반쯤 가림).
- **왼쪽 레일** — 햄버거 · 게임패드 · 채팅 · ? · 설정 · 내 아바타("로그인 후 아바타를 꾸며보세요").
- 맵은 2D 탑다운 픽셀 사무실(책상·의자·화분·INFORMATION 데스크). 사람이 가구 뒤에 숨지 않는다.

찍힌 것(`zep-mobile.png`): 같은 공간이 폰 폭에 그대로. **왼쪽 아래 가상 조이스틱**(방향키 대신), 아래 `+ · 💬 · 채팅을 입력해 주세요` 입력줄, 위 오른쪽 보내기·종·참가자 아이콘, 왼쪽에 아바타 꾸미기 버튼. 이름표도 그대로 두 줄. 오른쪽 가장자리가 살짝 잘린다.

공개된 사용법 기준(직접 확인 못 함 — 정지 화면이라): 방향키/클릭으로 걷기, 가까이 가면 말풍선·영상 대화가 열림, 미니맵, 포탈을 밟으면 다른 공간으로 넘어감. 이번 캡처에는 걷는 동작·말풍선·미니맵이 없다.

우리 마을 탭에 대응시키면(`out/direction.md` 3절 "누가 어디 있는지 항상 보인다"를 잇는다):

| ZEP | 마을 탭 |
| --- | --- |
| 이름표 두 줄(상태 + 이름) 상시 | **이름표 상시** — 이름 + 지금 상태(작업 중·감사 중·쉼) |
| 피플 목록(나 · 상태 · 내 자리 → · 묶음 접기 · 사람 줄 + 상태) | **참가자 목록 카드** — 팀별 묶음, 사람 줄에 상태, "내 자리로" 버튼 |
| GUIDE · MAP 포탈 타일 | **포탈로 방 이동** — 성문·집 문이 곧 방 입구 |
| 옆 채팅·메시지 버튼·반응 이모지 | **옆 채팅 = 그 방 대화록**, 반응은 판정 도장으로 |
| 오른쪽 위 종 · 참가자 수 · 초대하기 | 종(대표 차례 수) · 접속 인원 |
| 폰의 가상 조이스틱 | 폰 폭 마을 이동 방식 후보(결정 필요) |
