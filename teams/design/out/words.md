# 디자인 방이 만든 말 — 세어 본 것

2026-09-14 · 헨리. 대표 말 "착각하지 말라" 뒤. 잣대는 하나 — **이 말 사람들이 실제로 써?** 대표가 받아 썼는지는 잣대가 아니다.
내 파일(`direction.md` · `parts-plan.md` · `characters.json` · `style.md` · 로드맵)에서 우리가 만든 말을 뽑고, 사람들이 쓰는 말로 바꿀 수 있으면 옆에 적었다. 방에서 말할 때부터 오른쪽 말을 쓴다. 파일은 다음에 손댈 때 고친다 — 지금 통째로 갈아 쓰지는 않는다(M3 중).

| 우리가 만든 말 | 사람들이 쓰나 | 사람들이 쓰는 말 |
| --- | --- | --- |
| 인형 서울 | 안 쓴다 — 우리가 지었다. 대표가 받아 썼다 | 미니어처 서울 · 장난감 서울. 이름이 필요하면 대표가 짓는다 |
| 양식서 | 안 쓴다 | 스타일 가이드 |
| 부착물 | 안 쓴다 (건축 말) | 소품 · 액세서리 (안경·리본·갓) |
| 서울다움 넷 | 안 쓴다 | 서울처럼 보이게 하는 것 넷 |
| 8줄 채점표 | 안 쓴다 | 체크리스트 여덟 개 |
| 실루엣 규칙 | 반쯤 — 실루엣은 쓰는 말, "규칙" 붙인 건 우리 | 겉모습이 다 달라야 한다 |
| 빌보드 | 3D 하는 사람만 | (접었다 — 안 쓴다) |
| 컷어웨이 | 3D·건축 하는 사람만 | 집 안이 보이게 벽 하나를 뗀 것 |
| 배율 k · 세계 단위 | 안 쓴다 | 크기 배율 · 사람 키 1 기준 |
| colormap 띠 · UV | 3D 하는 사람만 | 색표 한 장 · 어느 칸이 옷인지 |
| 컷리스트 | 안 쓴다 | 이번엔 안 하는 것 |
| 양식 · 격자 | 격자는 쓴다. "양식" 은 우리 | 스타일 · 격자 |
| 키트 · 부품 | 부품은 쓴다. 키트는 레고 쓰는 사람만 | 부품 · 부품 세트 |
| 갓 · 한복 · 기와 | 쓴다 | 그대로 |
| 시안 · 렌더 · 팔레트 | 쓴다 | 그대로 |

세어 보니 열둘이 우리 말이고 넷이 사람들 말이다. 대표가 받아 쓴 건 "인형 서울" 하나가 제일 크다 — 그게 착각의 자리였다.
