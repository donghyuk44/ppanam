# 관제탑 네 탭 — 2판 (하영 목록에 맞춤)

2026-09-13 · 결정 47 ① 공동 프로젝트 · 쓴 사람 헨리. 1판은 `out/opsroom-tower-tabs.md`(가설), 2판은 하영의 `teams/marketing/out/opsroom-content.md`(대표 원문·기록으로 가른 쓴다/안 쓴다/빠져 있다)를 얹어 **줄을 빼고 넣은 것**이다. 읽는 사람: 테라(개발 M4 G-UX) · 톰(마케팅 방에 넣음).
지금 화면 기준: `server/public/app.js` `renderTowerAll`(1093) · `renderTowerPeople`(1169) · `personCard`(1223) · `renderTowerAsks`(1329) · `renderTowerTeams`(1341). 행 번호는 내 작업 사본 기준.
규칙 하나 — **1판의 줄은 하영 표에 "쓴다" 가 있을 때만 남는다.** "안 쓴다" 는 뺀다. "안 쓴다 ⚠"(기록이 없어 못 가른 다섯 자리) 는 대표 답 전까지 하영 판정대로 **빼되 ⚠ 를 달아** 둔다 — 답이 "쓴다" 면 그 줄만 되살린다(8절). 모양·글자 크기·색 토큰은 1판 4~6절 그대로, 여기 다시 안 쓴다.

## 0. 1판에서 2판으로 — 무엇이 바뀌나

| | 1판 | 2판 |
| --- | --- | --- |
| 줄 순서의 근거 | 코드와 참고 화면에서 내가 고름 | 대표가 관제탑에서 실제로 하는 다섯 걸음(하영 1절): **종 → 살았나 → 누를 것 → 방 → 요약 뒤 결정** |
| 개인 카드 | 5줄 | **3줄**(알약 · 하는 일 · 신호) + 부름 줄(결정 청한 것만) |
| 대표 카드 | 알약 + 3줄 | 알약 없음, **한 줄**(승인 대기 · 차례인 방) |
| 팀 카드 | 6줄 + 상황 접기 + 입력창·라운드 버튼 | 5줄. 게이지·대화록 수 뺌. 상황 접기·입력창·라운드 버튼은 ⚠ 뺌 |
| 전체 탭 | 대표 차례 → 팀 → 오늘 보고 | **종 → 살았나 → 누를 것 → 팀(방) → 오늘 보고** — 3-1절 내 몫 |
| 새로 넣는 것 | — | "왜 멈췄나" 한 마디(알약 옆) · C 카드 안에 결정 내용 · 살았나 한 줄 |

## 1. 순서 하나 — 네 탭이 같은 순서다

대표가 묻는 순서 ① 누가 나를 부르나 ② 살았나 죽었나 ③ 내가 정할 게 뭐가 있나 ④ 방으로 ⑤ 요약 들은 뒤 결정. 탭마다 카드의 줄이 이 순서로 선다 — 종 값(부름·승인 대기)이 맨 위, 살았나(알약·신호·하는 일)가 그 밑, 누를 것(부름 버튼·승인)이 그 밑, 방으로 가는 길(이름·발언)이 맨 밑. **자기 통계(오늘 지시·결정·발언·판정·대화록 수)는 어느 걸음에도 답하지 않아 전부 뺀다.**

## 2. 전체 탭 — 줄 순서를 ①②③④ 로 (3-1절, 헨리 몫)

지금(`renderTowerAll`): 타일 셋(대표 차례·승인 대기·요청 진행/완료) → `대표 차례` 카드 → `팀` 카드 → `오늘 보고`. ② "살았나" 가 팀 줄 안 `작업 중 이름` 으로만 있다 — 하영 3-1절.

```
┌ 타일 ──────────────────────────────────────┐
│  대표 차례 1   승인 대기 2   요청 1 / 3     │  ① 종 — 지금 그대로
└──────────────────────────────────────────────┘
┌ 살았나 ────────────────────────────────────┐
│ 일하는 중 9 · 대기 3 · 쉼 2                  │  ② 새 줄 — 열넷의 알약 합
│ 대기 — 안젤(대표 답) · 다니엘(승인) · 마크   │     일하지 않는 사람만 이름 + 왜
│ 쉼 — 노라 · 빅터 (신호 40분 전)              │
└──────────────────────────────────────────────┘
┌ 대표 차례 ─────────────────────────────────┐
│ 디자인 · 결정 요청 — 팔레트 색 수           │  ③ 누를 것 — 지금 그대로 (누르면 방)
│ 승인 C · 마케팅 · 로드맵 …  [펼침]           │     C 는 카드 안에 내용 (6절)
└──────────────────────────────────────────────┘
┌ 팀 ────────────────────────────────────────┐
│ 디자인  [진행 중]  R14 · 마일스톤 2 · 2/4    │  ④ 방 — 진행 막대 분수 더함
│   ● 헨리  ○ 클레멘타인  ○ 마크               │     칩 점 = 알약 색 (② 를 팀 단위로)
└──────────────────────────────────────────────┘
┌ 오늘 보고 N ───────────────────────────────┐  ⑤ 맨 밑 — 결정이 아닌 보고
```

- **살았나 줄(새 카드)** — 열넷의 일 상태(`people[id].state`)를 세어 `일하는 중 n · 대기 n · 막힘 n · 쉼 n`(0 은 숨김). 그 밑에 **일하지 않는 사람만** 이름 + 괄호에 왜(7절 `why`). 전부 일하는 중이면 한 줄 `열넷 다 일하는 중` 으로 끝. 결정 31·58 "죽었나" 를 한 눈에 답하는 자리 — 4절 사람 카드를 열넷 다 훑지 않아도 된다. 카드 클래스는 `dash__card`, 줄은 `dash__row`(누르면 그 사람의 방).
- **대표 차례 카드** — 지금 그대로. 방 줄 옆 `bossWhyOf` 문구 유지. C 줄은 6절대로 펼침을 단다.
- **팀 카드** — 지금 줄에 둘 더한다: 마일스톤 뒤 `2/4`(1판 팀 탭 3줄의 분수) · 사람 칩 줄(22px, 점 색 = 알약 색). `작업 중 이름` 글자는 칩 점으로 대신하니 뺀다. `승인 대기 n` 은 남는다(③).
- **오늘 보고** — 맨 밑 그대로. 결정 52 로 종·대표 차례가 결정을 맡고 여기는 보고만.
- 요청 타일은 `요청 1 / 3` 그대로 — 결정 50 원문.

## 3. 팀 탭 — 다섯 카드 (하영 3절)

```
┌──────────────────────────────────────────────┐
│ 디자인                          [대표 차례]  │  1줄 이름(누르면 방) + 알약        쓴다
│ R14 · 마일스톤 2 인형 열다섯                 │  2줄 라운드·단계                    쓴다
│ ▓▓▓▓░░░  2/4                                 │  3줄 진행 막대 + 분수               쓴다
│ 승인 대기 2 · ● 헨리 일하는 중 · 신호 2분 전  │  4줄 숫자 줄 (0 은 숨김)            쓴다
│ 헨리 · app.js 고치는 중 · 3분 전             │  5줄 지금 만지는 것                 쓴다
│ 3분 전 · 헨리 · "색은 나중에. 실루엣이…"      │  6줄 마지막 발언 — 시각을 앞에       쓴다
└──────────────────────────────────────────────┘
```

| 1판 줄 | 하영 | 2판 |
| --- | --- | --- |
| 팀 이름 → 방 · 상태 알약 | 쓴다 | 그대로. 알약 옆에 왜 멈췄나(7절) — `대기 · 대표 답` |
| R · 마일스톤 제목 | 쓴다 | 그대로 |
| 진행 막대 + `2/4` | 쓴다 | 그대로 |
| 반박 게이지 점 셋 / `반박 n/3` | 안 쓴다 | **뺀다.** 3회 다 쓰면 종 BOSS_WHY 에 뜬다 |
| `대화록 N건` | 안 쓴다 | **뺀다** |
| `승인 대기 n` | 쓴다 | 4줄에 남는다 |
| `이름 작업 중 · 신호 N분 전` | 쓴다 | 4줄 — 칩 점 + 이름 + `신호 N분 전`. 문구는 로드맵 ⑥ 작전실 말(하영)이 정한다 — 여기선 자리만 |
| 지금 만지는 것 | 쓴다 | 5줄 그대로. 개인 탭 2줄과 같은 값 |
| 마지막 발언 세 줄 + `N분 전` | 쓴다 — 시각이 핵심 | **`N분 전` 을 줄 맨 앞에**, 굵기 500 --ink-2. 본문은 한 줄 자름(세 줄 → 한 줄). "왜 모두 멈춰있니" 는 시각을 보고 나온 말 |
| 상황 접기 `하는 중/한 것/남은 것/이슈` | 안 쓴다 ⚠ | **⚠ 뺀다.** 데이터가 개발팀에만 있다. 8절 ④ |
| 입력창 `지시하기 / 라운드 주제 / 톰에게` | 안 쓴다 ⚠ | **⚠ 뺀다.** 8절 ① |
| `라운드 열기 / 닫기` 버튼 | 안 쓴다 | **뺀다.** 14/14 system |

- 팀원 칩(1판 5줄)은 따로 줄을 안 두고 4줄 사람 이름 앞의 점으로 접는다 — 살았나 답이 4줄 하나에 모이게.
- 카드 순서 고정(총괄·마케팅·개발·디자인·재무), 대표 차례 카드 왼쪽 --bad 띠 — 1판 그대로.

## 4. 개인 탭 — 열넷 + 대표 (하영 2절)

```
┌──────────────────────────────────────────────┐
│ [댄]  함동혁 · 대표                          │  대표 카드 — 알약 없음
│ 승인 대기 2 · 차례인 방 디자인               │  한 줄 (① ③)
└──────────────────────────────────────────────┘
디자인 3 ─────────────────────────────── ▾       묶음 머리 (접기) + 부름 점    쓴다
┌──────────────────────────────────────────────┐
│ [헨]  헨리 · 메인 디자인    [대기 · 대표 답] │  1줄 칩 + 이름 · 자리 + 알약(왜)  쓴다 — 첫째
│ characters.json 쓰는 중                      │  2줄 지금 하는 일                 쓴다
│ 신호 2분 전                                  │  3줄 신호만                       쓴다
│ ▸ 결정 청함 · 12분 전 · "팔레트 색 수를…"     │  4줄 결정 청한 부름만 (없으면 없음) 쓴다
└──────────────────────────────────────────────┘
```

| 1판 줄 | 하영 | 2판 |
| --- | --- | --- |
| 대표 카드 알약 `자리에 / 자리 비움` | 안 쓴다 | **뺀다** |
| 대표 카드 2줄 `오늘 지시 N · 승인 대기 N · 차례인 방` | 쓴다 — 뒤 둘만 | `승인 대기 N · 차례인 방 …` 한 줄. `오늘 지시` 뺀다 |
| 대표 카드 3줄 `결정 N · 마지막 지시 N시간 전` | 안 쓴다 | **뺀다.** 대표 카드는 1줄 + 1줄 |
| 묶음 머리 `디자인 3` + 접기 + 부름 점 | 쓴다 | 그대로 |
| 1줄 이름 · 자리 · 알약 | 쓴다 — 첫째 | 그대로. 알약 글자에 **왜**를 붙인다: `대기 · 대표 답` · `대기 · 승인` · `막힘 · 세션 꺼짐` · `대기 · 라운드 없음`. 일하는 중·쉼은 왜 없음(7절 `why`) |
| 2줄 지금 하는 일 | 쓴다 | 그대로(두 줄 자름, 일하는 중 아니면 시각 붙임) |
| 3줄 `신호 N분 전` | 쓴다 | 남는다. 문구는 하영이 작전실 말에서 쓴다(하영 4절 "안 죽었어요") — 값 자리만 |
| 3줄 `오늘 발언 N` · `판정 N` | 안 쓴다 ⚠ | **⚠ 뺀다.** 8절 ③ |
| 4줄 부름 버튼 → 방 그 말로 | 쓴다 | 남는다 — **`bossCall.ask` 가 참인 것만**(결정 52 종 배지와 같은 조건). 보고는 안 뜬다. 글자 `대표 불렀음` → `결정 청함` |
| 5줄 일지 첫 문장 + 펼침 | 안 쓴다 ⚠ | **⚠ 뺀다.** 결정 40 은 "상태". 8절 ② |

- 카드가 3줄이라 폰에서 한 장 ≈ 95px → 세로 915 에 아홉 장. 열넷이 두 화면 안 — 접기는 남기되 처음엔 다 펼침(1판 그대로).
- 순서·정렬 없음·칩 색 — 1판 3절 그대로.

## 7. 서버 값 — 1판 7절에서 바뀐 것 (개발팀 몫)

- **안 쓰게 된 값** — `people[id].todaySay` · `todayVerdict` · `journalFirst` · `boss.todayOrders` · `todayDecisions` · `boss.lastOrder`. ⚠ 자리라 **지우지 말고 화면에서만 뺀다** — 대표 답이 "쓴다" 면 되살린다(8절). 열다섯 번 일지 읽기는 안 부르니 부담이 준다.
- **새 값 하나** — `people[id].why`: 일하지 않을 때 이유. `boss`(대표 답 기다림) · `approval`(승인 기다림) · `session`(세션 꺼짐·신호 끊김) · `round`(라운드 없음) · `null`(일하는 중·쉼). 종 메뉴 BOSS_WHY 가 방 단위로 이미 세는 것을 사람 단위로. 글자는 4절 알약 표.
- **있는 값 그대로** — `state`(결정 58 ①) · `lastSignal` · `doing` · `bossCall{ id, ts, text, ask }`(결정 52 의 `ask` 로 4절 부름 줄을 거른다) · `needsBoss` · `approvals.pending` · `round` · `milestone*`.
- **승인 카드** — C 카드 펼침(6절)에 쓸 `detail` 전문과, `--roadmap` 이면 제안 파일의 `milestones[].n·title` 과 `cutList` 를 `/api/approvals` 에 실어 준다. 지금은 `what · detail · files` 뿐(`approve.mjs --show` 로 확인).
