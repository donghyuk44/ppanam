# 작전실 말 — 우리 말을 사람 말로 (8판)

8판 — 2026-09-16, 결정 189 정리(하영). 지금 방·화면에서 쓰는 낱말과 뜻만 남겼다. 옛 판(7판, 704줄)과 거기 있던 3절(세 장면의 말 — 화면에 박힌 글자 한 줄씩)·7절(테라에게)·8절(대표 차례)은 `archive/0916/marketing/opsroom-words-7.md` 에 글자 그대로 있다. 화면에 붙은 글자의 정본은 화면(`server/public`)이고, 이 사전은 낱말과 뜻이다.
대표 원문(결정 95): "워딩, 단어선택, 이것들이 너무 실제로 안쓰는 단어들밖에 없어. 문장도 너무 부자연스러워. 우리 바이블 보면 어투나 이런거 학습하기로 했는데 이유가 자연스러운 대화를 위해서야."
읽는 사람: 테라(화면 글자를 이 표대로 — 결정 43 ⑥ "하영이 쓰고 개발이 그대로 붙임") · 열다섯 자리 전부(방에서 말할 때 왼쪽 열 말을 쓰지 않는다) · 대표(결과를 화면에서 읽는다).

## 0. 규칙 둘 (옛 0절 + 0-3 표준어 잣대 — "사전 0-3" 은 이 절이다)

1. **사람들이 실제로 쓰는 말만 화면과 방에 쓴다.** 우리가 만든 말은 파일과 코드 안에서만 산다. 잣대는 "대표가 쓴 적이 있나" 가 아니다 — 결정 96 "관제탑·마을·바이블·바깥눈 — 이것들도 절대 보통 안 쓰는 말이야. 니네 편한 단어라 내가 몇 번 써 준 거지." 잣대는 하나, **처음 듣는 사람이 안 물어보고 아는 말인가.**
2. **쉬운 말은 지어낸 말이 아니라 남들이 이미 쓰는 말이다.** 대표 원문(09-16 07:4x) "이게 실제 쓰는 단어가 맞아? 어디 회사나 서비스나 플랫폼에서 이런 단어를 사용하냐". 지라·아사나·노션·슬랙·플로우·잔디 같은 데서 안 쓰는 말이면 안 된다. 보통 한국어(된 것·막힌 것)는 그대로 두고, 탭·알약·카드 머리처럼 다른 서비스에 같은 자리가 있는 글자는 그 서비스 말로.

새 낱말은 이 둘로 하영이 정한다(대표 결정 09-16 10:07 "새 낱말은 하영이 우리 낱말 규칙표대로 정한다"). 근거는 열어 본 페이지에서 그 글자가 보이는 줄 하나 그대로 — 주소만 온 줄은 미확인이다. 근거 확인은 다니엘, 잣대를 맞게 댔는지는 안젤.
바꾸는 담당: 화면 글자·`cast.json` title 은 테라가 한 회차에 커밋 하나, 이 사전은 하영이 같은 회차에. 규칙 파일 고침은 단계가 끝날 때 한 번에 — 예외는 대표 직접 지시와 이미 통과한 교체(나리 정리안 170 ⑤).
방에서 하는 말은 옆 장 `plain-words.md`(결정 198) — 번호·명령어·우리끼리 말 스무 줄을 보통 말로. 이 사전 3절은 화면 글자, 그 표는 방 말이다.

3. **비유로 쓰지 않는다 — 아래 스물여섯은 물리적·문자 그대로의 뜻일 때만.** 대표 원문(09-18 10:5x, 결정 216, 전문 `teams/hq/out/대표-원문-0918.md` 8절): "한국어로 말할 때는 다음 단어를 비유적·추상적 의미로 쓰지 않는다. 물리적·문자 그대로의 뜻일 때만 허용한다." 규정집 한 장은 `out/한국어-낱말-규정집.md`. 안젤이 방 말·보고 글에서 어긋난 줄을 센다.

### 비유로 쓰면 안 되는 낱말 스물여섯 (대표 원문 글자 그대로 — 동사 스물 · 명사 여섯)

"안 되는 예" 는 지어낸 게 아니라 우리가 오늘까지 실제로 쓴 꼴이다(방 기록·사전·인수인계에서). 괄호 안 예외는 대표 원문의 괄호 그대로.

| 낱말 | 안 되는 예(비유) → 대신 쓰는 말 | 되는 예(문자 그대로) |
| --- | --- | --- |
| 잡다/잡히다 | "안젤이 잡았다" → 안젤이 찾았다 · 지적했다 / "검사기에 잡힌다" → 검사기가 표시한다 | 손잡이를 잡다 |
| 붙다/붙이다 | "테라가 화면에 붙인다" → 화면에 넣는다 · 적용한다 / "시안이 붙었다" → 시안대로 됐다 | 스티커를 붙이다 |
| 걸리다/걸다 | "검사에 걸린다" → 검사가 표시한다 / "일이 걸려 있다" → 남아 있다 · 기다리고 있다 | 옷을 옷걸이에 걸다 |
| 세우다(계획 외) | "기준을 세우다" → 기준을 정하다 / "규칙을 세우다" → 규칙을 만들다 | 계획을 세우다(허용) · 기둥을 세우다 |
| 서다(사람 외) | "검토 결과가 선다" → 검토 결과가 나온다 / "통과 조건이 서면" → 통과 조건이 정해지면 | 사람이 서다 |
| 갈리다/가르다 | "의견이 갈린다" → 의견이 다르다 / "쓴다·안 쓴다를 가른다" → 나눈다 · 정한다 | 장작을 가르다 |
| 굴다/굴리다 | "서버를 굴린다" → 서버를 켠다 · 실행한다 / "못되게 군다" 는 사람 말이라 그대로 | 공을 굴리다 |
| 끌다/끌리다 | "시간을 끈다" → 미룬다 / "마음이 끌린다" → 좋다 · 하고 싶다 | 의자를 끌다 |
| 받치다/받쳐주다 | "근거가 받쳐 준다" → 근거가 있다 · 뒷받침한다(다른 낱말) | 책으로 받치다 |
| 논다 | "자리가 논다" → 비어 있다 · 쉬고 있다 / "사람이 논다" → 일이 없다 · 대기 | 아이가 논다 |
| 밀리다/밀다 | "일이 밀렸다" → 늦어졌다 · 쌓였다 / "다음으로 민다" → 다음으로 미룬다 | 문을 밀다 |
| 먹히다 | "말이 먹힌다" → 말이 받아들여진다 · 통한다 | 밥이 안 먹힌다 |
| 조이다/조여오다 | "시간이 조여 온다" → 시간이 얼마 안 남았다 | 나사를 조이다 |
| 끊다/끊기다(사람 외) | "연결이 끊겼다" → 연결이 안 된다 · 안 이어진다 / "말을 끊다" → 말을 멈추게 하다 | 사람과 연락을 끊다(허용) · 줄을 끊다 |
| 넓히다/좁히다(물리 외) | "낱말 꼴을 좁힌다" → 낱말 꼴을 줄인다 · 한정한다 / "범위를 넓힌다" → 범위를 늘린다 | 길을 넓히다 |
| 열다/닫다(물리 외) | "회차를 연다/닫는다" → 회차를 시작한다/끝낸다 / "요청을 연다" → 요청을 보낸다 · 시작한다 | 문을 열다 · 창을 닫다 · 파일 열기(프로그램 메뉴 글자 그대로) |
| 돌다/돌리다(물리 외) | "검토를 돌린다" → 검토를 실행한다 · 시작한다 / "회차가 돈다" → 회차가 진행된다 / "같은 자리를 세 번 돈다" → 세 번째다 | 바퀴가 돌다 |
| 타다(물리 외) | "흐름을 탄다" → 흐름을 따른다 / "분기를 탄다" → 그 경우로 간다 | 버스를 타다 |
| 묶다/묶이다(물리 외) | "요청에 묶는다" → 요청에 같이 넣는다 / "세 묶음" → 세 가지 · 세 항목 | 끈으로 묶다 |
| 풀다/풀리다(물리 외) | "막힌 게 풀렸다" → 해결됐다 / "뒤에 걸린 게 풀리면" → 앞 일이 끝나면 | 매듭을 풀다 |
| 축 | "기준 축" → 기준 / "날짜 축" → 날짜 줄 · 가로줄(그림의 x축은 문자 그대로) | 바퀴 축 · 그래프의 x축 |
| 겹 | "규칙이 겹으로 있다" → 두 번 있다 · 중복이다 | 종이 두 겹 |
| 그림(picture/scenario 의미) | "전체 그림" → 전체 계획 · 전체 모습 / "그림이 안 나온다" → 결과가 안 보인다 | 사진·그림 파일(picture) |
| 판(plate/edition 이 아닌 situation 의미) | "판이 바뀌었다" → 상황이 바뀌었다 / "한 판 채워 본다" → 한 번 채워 본다 | 사전 8판 · 시안 3판(edition, 허용) · 철판 |
| 틀 | "글 틀" → 글 양식 · 형식 / "40줄 틀" → 40줄 양식 / "틀은 그대로" → 형식은 그대로 | 창틀 · 얼음 틀 |
| 결 | "새 결" → 새 디자인 · 새 스타일 / "결이 같다" → 방향이 같다 · 같은 식이다 | 나뭇결 · 머릿결 |

우리 파일 이름·제목에 든 "틀"(`screen-text-frames.md` "글 틀", `40-fold.md` "40줄 틀")과 "결"(피그마 페이지 "새 결")은 파일 이름은 그대로 두고 글 안에서만 양식·디자인으로 바꾼다 — 파일 이름 바꾸기는 여러 팀 경로에 들어 있어 따로 승인.

### 단추·명령·선택지 (대표 13:02 "가 라는 명령어도 자연어가 아니잖아")

글자 번호(가·나·다, ①②, A·B)가 아니라 **고르는 내용 그대로** — 결재 카드는 승인 · 반려 · 보류, 슬래시 명령은 /시작 · /마무리 · /검토. 대표가 고를 말이 곧 그 일의 이름이다.

### 때는 시각이 아니라 "무엇이 되면" (결정 187·188)

"N분 안 · N분마다 · 매시 정각 · 06:30 · 매일" 처럼 우리가 정한 시각은 뺀다 — 대신 조건으로: 카드가 뜨면 · 표가 새로 오면 · 대표가 화면을 여시면 · 답이 없으면. 시간 관련 규칙 전부(회차 수 상한 포함) 없음. 상대 시각 표시("3분 전에 움직임")와 인물 이야기의 시간은 규칙이 아니라 그대로.

## 4. 문장 버릇 — 결정 95 + 인격 README 12개

화면과 방에서 **"~요" 로 말한다.** "~습니다" 는 검토 결과 카드 한 줄과 시스템 안내에만. 한 문단에 "입니다" 가 셋 넘으면 문서지 말이 아니다.

| 버릇 | 대신 | 왜 |
| --- | --- | --- |
| "…하는 것이 맞습니다" | "맞아요" / "…해야 해요" | 판단을 명사로 싸서 한 번 더 미룬 말 |
| "…임을 확인했습니다" | "봤어요, 맞아요" / "열어 봤는데 있어요" | 확인은 동사다 |
| "…에 대해 말씀드리자면" · "다음과 같습니다" | 그냥 말한다 | 문서 서두 |
| "확인했습니다" · "진행하겠습니다" · "알겠습니다" 로 시작·끝 | 답으로 시작 — "됐어요", "지금 해요", "내일 첫 줄에 올릴게요" | 접수증 |
| 제목을 명사로 끝냄 — "대리 결정 요청 실패" | 문장으로 — "대리 결정을 못 받았어요" | 명사 제목은 기계 로그 |
| "실측" · "산출" · "반영" · "적용" · "수행" · "처리" | "재 봤어요" · "냈어요" · "넣었어요" · "고쳤어요" · "했어요" | 한자어 동사는 회사 문서 말 |
| "~함" · "~됨" 으로 끝나는 줄 | 문장으로 끝낸다 | 메모지 말투 |
| 형용사 셋 나열 | 하나 | README 5번 |
| 상대가 누구든 같은 말끝 | 대표 존댓말 · 동료는 그 사람 말투 | README 8번, 결정 44 |
| 문장마다 이름 | 첫머리 한 번 | README 9번 |
| 사과 둘 이상 · "죄송합니다" | 한 번, 그다음은 고친 것 | README 11번 |
| 보고에 물음표 | 보고는 마침표로 끝낸다 — 물음표가 붙으면 종이 울린다(결정 52) | |

## 5. 용어 한 줄 뜻 — 카드의 물음표를 누르면

방과 파일에선 우리가 계속 쓰는 말이라 뜻을 한 줄씩 둔다. 물음표 툴팁 = 오른쪽 줄 그대로.

| 우리 말 | 화면 글자 | 대표가 읽는 한 줄 |
| --- | --- | --- |
| 신호 | N분 전에 움직임 | 이 사람이 마지막으로 뭔가 한 시각이에요. 오래 조용하면 죽은 게 아니라 할 일이 없거나 답을 기다리는 거예요. |
| 차례 (대표 차례) | 대표님 할 일 / 승인 대기 | 대표님이 정하거나 눌러야 다음으로 가는 일이에요. 보고는 여기 안 들어가요. |
| 부름 (대표 부름) | 답변 대기 | 누가 대표님께 뭘 정해 달라고 했는데 아직 답이 없는 상태예요. 누르면 그 말로 가요. |
| 막힘 — 일 / 사람 | 막힌 것 (일) / 차단됨 (사람 알약) | 막힌 것은 누가 풀어야 하는 일이에요. 차단됨은 그 일 때문에 못 움직이는 사람이에요. 일 하나에 사람 여럿이 막힐 수 있어요. |
| 승인 (A·B·C) | 결재 — 혼자 해도 됨 · 사장이 봄 · 대표님이 정함 | 일마다 누가 허락하나예요. A 는 팀이 그냥 하고, B·C 는 나리가 대표님 대신 정하고, 결제·외부 공유·발송만 대표님이 정해요. |
| 요청 블록 | 요청 | 한 팀이 다른 팀에 뭘 해 달라고 한 것과 그 대화예요. 톰이 옆에서 봐요. |
| 회차 · 단계 · 목표 | 28회차 · 5단계 · 목표 | 회차는 한 번 모여 일하고 검토받는 단위, 단계는 회차가 모여 낸 것 하나, 목표는 단계가 다 모이면 되는 것이에요. |
| 검토 결과 | 승인 · 반려 · 보류 | 감사 둘이 본 결과예요. 승인이면 다음으로, 반려면 고쳐서 또 보여요, 보류면 대표님께 가요. |
| 판정 대기 | 검토 중 | 낸 것을 감사 둘이 보는 중이에요. 다 보면 승인·반려·보류 중 하나가 와요. |
| 계정 한도 (codex·gemini) | 계정 한도 · N일까지 | 다른 회사 AI 의 계정이 한도에 걸려 못 오는 거예요. 우리가 고칠 수 없고 날짜가 풀어요. |
| 눌렀다 → 됐다 | 됐어요 — 무엇, 어디에 전해졌어요 · 시각 | 대표님이 누른 게 어디로 갔는지예요. 이 줄이 남아 있으면 전송된 거예요. |
| gated 단계 · `bossGates` | 대표님이 여실 단계 | 대표님 답이 있어야 시작할 수 있는 단계예요. 계획표에 "대표 방향 뒤" 처럼 적힌 것들이에요. |
| 같은 자리 (분석) | 같은 자리에서 N번째 | 같은 단계·같은 카드를 몇 번째 도는지예요. 한 번 승인되면 그 자리는 닫히고, 그 뒤 같은 번호는 새 자리로 세요. |
| 완료 조건 | 완료 조건 | 항목 하나가 끝났는지 기계가 확인하는 한 줄이에요. 이게 통과해야 닫혀요. |
| 사이트맵 | 사이트맵 | 화면에 무엇이 어디 있나 한 장이에요. 탭·블록·단추가 어디 있고 어디로 가는지요. |
| 주의사항 | 주의사항 | 전에 넘어진 자리를 한 줄씩 모은 목록이에요. 일 시작 전에 읽어요. |
| 진행 현황 | 진행 현황 | 작업 보드에서 도구가 뽑은 표예요. 톰이 밑에 한 줄씩 적어요. |
| 큰 숫자 셋 (결정 192) | 정할 것 · 막힌 것 · 오늘 끝난 것 | 정할 것은 대표님이 정하거나 눌러야 다음으로 가는 일의 수예요(결재 대기 + 답변 대기). 막힌 것은 누가 풀어야 넘어가는 일의 수예요. 오늘 끝난 것은 작업 보드(`state/work.json`)에서 오늘 통과로 바뀐 일의 수예요 — 카드 통과 수가 아니라 일 수(나리). 보드 항목에 통과로 바뀐 날짜 칸(doneAt)을 테라가 넣고 그걸 센다 |

## 7. 시스템 안내 — 하네스가 방에 넣는 말도 사람 말로

자동 안내는 나리 이름으로 뜬다(결정 129). 잣대는 같고 하나 더 — **시스템은 "~요" 가 아니라 "~습니다" 로 끝낸다.** 사람 열다섯과 말투가 같으면 누가 시스템인지 안 보인다. 명사로 끝내지 않는다(4절). 나리 본인의 말은 제 말투라 말끝으로 갈린다.

| 지금 (어디) | 바꿀 말 |
| --- | --- |
| `라운드 28 시작 · 마일스톤 5` (bus.mjs) | **28회차를 시작합니다 — 5단계 "캐릭터 설정 다시 쓰기".** |
| `라운드 28 종료 · PASS` | **28회차를 승인으로 마칩니다.** / **28회차를 마칩니다 — 반려.** |
| `라운드 28 닫기 거부 (PASS) — …` | **28회차를 아직 못 닫습니다 — (이유).** 이유 넷: "검토 결과가 없습니다" · "마지막 검토가 반려였습니다" · "감사 둘의 판정 완료 줄이 없습니다" · "대표님 답을 기다리는 방입니다" |
| `마일스톤 5 통과 — 로드맵에 pass 로 기록` | **5단계가 끝났습니다. 계획표에 적었습니다.** |
| `마일스톤 6 착수 — 로드맵의 now 를 옮겼습니다.` | **6단계를 시작합니다.** |
| `판정 시작 — 하영. 안젤 → 다니엘 순서.` | **검토를 시작합니다 — 안젤, 그다음 다니엘.** |
| `판정 완료 — 안젤·다니엘 모두 통과. …` | **검토 끝 — 안젤·다니엘 모두 승인. 하영이 회차를 마칠 수 있습니다.** |
| `판정 완료` | **검토 끝.** |
| `다니엘이 두 번 물어도 첫 줄에 판정을 쓰지 않았습니다. 판정 흐름을 멈춥니다` | **다니엘이 두 번 물어도 첫 줄에 결과를 안 적었습니다. 검토를 멈춥니다.** |
| `대리 결정 — C 승인 apr_… 를 대표 대신 통과시켰습니다 (…)` | **나리가 대표님 대신 정했습니다 — 결재 apr_… 승인. 이유: …** |
| `대리 결정 — 톰·제리: …` | **나리가 대표님 대신 답합니다 — …** |
| `대표 차례가 … 답이 없지만 대리로 정하지 않습니다 — 돈이 나가거나 바깥으로 나가는 일이라 …` | **대신 정하지 않고 기다려요 — 결제·외부 공유는 대표님만 정하세요: …** |
| `요청 블록 req_… 이 열렸습니다 — dev/guide 와 1:1, 톰이 감시자.` | **개발팀 테라에게 요청을 열었습니다. 톰이 옆에서 봅니다.** |
| `승인 apr_… 실행 결과 — 푸시 완료` | **결재 apr_… 대로 올렸습니다.** |
| `승인 apr_… 실행 결과 — 밀지 않았습니다` | **결재 apr_… 는 올리지 못했습니다 — (이유).** |
| `로드맵 교체 — roadmap.proposed.json 를 roadmap.json 으로 옮겼습니다 (마일스톤 7개).` | **계획표를 바꿨습니다 — 7단계짜리.** |

한 줄로 안 되는 것(`… 세션에 넣지 못했습니다 — (오류)` 류)은 대표가 아니라 개발이 읽는 줄이다 — 방에 띄우지 말고 서버 기록으로만(테라 몫).
