읽는 사람: 테라(개발 M4 G-UX 에서 이 표대로 고침) · 헨리(설계 2판).
지금 화면 기준: 개발 방 `out/shots/r22-tower-people-412.png` · `r22-tower-asks-412.png` + `server/public/app.js` 1069~1517행(전체·개인·요청·팀 탭 그리는 코드). 행 번호는 마케팅 작업 사본 기준이라 테라 쪽에서는 움직였을 수 있다 — 함수 이름(`renderTowerPeople`·`personCard`·`renderTowerTeams`)으로 찾는 게 안전하다.
새 화면을 그리지 않는다. 지금 있는 항목마다 **쓴다 / 안 쓴다 / 빠져 있다** 만 가른다.

## 0. 무엇을 근거로 갈랐나

나는 대표가 아니다. 그래서 "대표가 이걸 볼 것 같다" 로 안 갈랐고, **대표가 실제로 한 말과 남긴 기록**으로만 갈랐다.

- 대표 원문 — `teams/dev/decisions.md` 20·31·40·47·50·52·58 (전부 09-13, 관제탑·상태·버튼에 대해 대표가 직접 한 말) + 대화록 두 줄: 마케팅 04:06Z "그리고 안젤이랑 다니엘 죽어잇는거같은데" · 디자인 01:42Z "왜 모두 멈춰있니? 대답해봐".
- 대표가 누른 것 — `state/approvals.jsonl` 의 대표 판정 3건(전부 C). 앱에서 누른 것 **1건**(apr_79299ea8, 04:10Z, 이유 빈칸 — "누를 수 있는게 없네" 5분 뒤). 나머지 2건은 reason 에 "독립검수가 읽어 드리고 받은 버튼 답" 이라 적혀 있다 — 앱 밖이다.
- 대표가 친 말 — 대화록에서 하네스 전달·옮겨 적은 것(파일 경로·결정 번호가 든 긴 글)을 빼고 대표가 직접 친 message: 마케팅 9 · 디자인 3 · 개발 0 · **총괄 0** = 12. 전부 방 안이다.
- 라운드 열고 닫기 — 마케팅 대화록 round_start 14건 전부 actor `system`. 대표가 관제탑 카드로 라운드를 연 적은 0.
- **기록이 없는 것** — 관제탑 안에서 어느 탭·어느 버튼을 눌렀는지는 서버가 안 남긴다. 그래서 "안 쓴다" 중 기록 부재로 가른 것은 ⚠ 를 달고 4절에서 대표에게 묻는다.

가르는 규칙: **쓴다** = 대표 원문·기록이 그 항목을 찾거나 눌렀다고 보여 준다. **안 쓴다** = 대표가 관제탑을 열 때 묻는 질문(1절) 어느 것에도 답하지 않고, 찾은 기록도 없다. **빠져 있다** = 대표가 찾았는데 화면에 없다.

## 1. 대표가 관제탑에서 실제로 하는 순서

대표 원문을 시간순으로 놓으면 순서가 나온다. 다섯 걸음이고, 질문 하나씩이다.

| 걸음 | 대표가 묻는 것 | 근거 |
| --- | --- | --- |
| ① 오른쪽 위 종 숫자를 본다 | "누가 나를 부르나" | 결정 52 — 종 배지를 보고 "마케팅팀이랑 디자인팀이 승인요청하는데 뭐야 이거". 실제 승인 요청 0건, 보고를 부름으로 읽음 |
| ② 살아 있나 죽었나를 본다 | "얘네 일하고 있나, 죽었나" | 결정 31 "5분에 한 번은 안죽었어요 알림" · 결정 58 "관제탑 체크하는데 뭔가 이상해"(열넷이 다 '잠') · 04:06Z "안젤이랑 다니엘 죽어잇는거같은데" · 01:42Z "왜 모두 멈춰있니". **관제탑을 여는 제일 큰 이유가 이것이다** |
| ③ 누를 것을 찾는다 | "내가 정할 게 뭐가 있나" | 결정 20 "내가 누를 수 있는게 없네" → 5분 뒤 앱에서 승인 1건 누름(apr_79299ea8) |
| ④ 방으로 간다 | "말을 건다" | 대표가 직접 친 말 12건 전부 방 안. "안젤, 이거 봐줘"(×2) · "다니엘, 이거 봐주세요" · "하영아 …". 관제탑에서 말한 기록 없음 |
| ⑤ 결정은 요약을 들은 뒤 한다 | "이게 뭔지 알아야 누르지" | C 3건 중 2건이 앱 밖 — 독립검수가 내용을 읽어 주고 버튼 답. 앱의 C 카드만 보고 판정한 건 1건 |

⑤ 가 뜻하는 것: 지금 C 카드(무엇·왜·산출물 링크·승인/반려)는 **결정에 필요한 내용이 카드 안에 없다.** 대표가 사람에게 읽어 달라고 했다.

## 5. 대표에게 확인할 것 — 넷 (⚠ 다섯 자리, 발언·판정은 한 질문)

기록이 없어서 못 가른 것. 답이 오면 이 표를 고친다. 답이 안 오면 ⚠ 판정대로 간다.

① 관제탑 팀 카드 입력창에서 지시를 쳐 보신 적 있으세요, 아니면 늘 방에서 치세요? → 입력창·라운드 버튼 존폐
② 개인 카드의 「나는 …」 일지 줄을 눌러 보신 적 있으세요? → 5줄 존폐
③ 오늘 발언·판정 숫자를 보고 뭔가 판단하신 적 있으세요? → 3줄의 뒤 둘 존폐
④ 개발팀 카드의 "상황 · 하는 중 N · 한 것 N · 남은 것 N" 줄을 펼쳐 보신 적 있으세요? → 상황 접기 존폐 (지금은 개발팀 카드에만 뜬다)

## 한 줄 요약 (헨리·테라용)

대표는 관제탑에서 **종 → 살았나 → 누를 것 → 방** 순서로 움직인다. 살리는 건 알약·하는 일·신호·부름 버튼·승인 대기·마일스톤 N/M. 빼는 건 자기 통계·발언 수·판정 수·대화록 수·게이지·입력창·라운드 버튼. 빠진 건 누를 선택지 카드와 C 카드 안의 내용, 그리고 "왜 멈췄나" 한 마디.
