## ① 대표 지시와 우리 조건

대표 지시(09-13): "오픈소스 같은 거 한 명한테 시켜서 쫙 리서치만 해서 팀원들이 보고 쓸 만한 것 골라도 되겠다." 그래서 아래는 **고르는 사람이 따로 있는 목록**이다 — 테라(개발)·헨리·클레멘타인(디자인)·하영(마케팅)이 읽고 자기 라운드에 가져갈 것을 고른다. 우리 조건(사실): Node 서버 + 프레임워크 없는 바닐라 JS 웹(`server/public/app.js`·`world.js`), 마을은 캔버스 2D 에서 **Three.js 로 그리기 층만 교체**(결정 16), 인물은 2D 그림 빌보드·건물은 도형+텍스처(결정 5, 헨리 로드맵 결정 33), 기준 기기 Android Chrome, 폰트·라이브러리는 cdnjs/jsDelivr CDN 만, 팀에 손으로 그리는 사람 없음, 참고 서비스는 네이버 홈·레딧 홈·ZEP(결정 34: 종+배지 알림, 카드형 목록, 세로 메뉴, 가상 사무실의 아바타·이름표·참가자·방 이동·옆 채팅). 후보 24개 전부 저장소 페이지를 직접 열어 확인했고(확인자 검증), 라이선스·마지막 활동·스타 수는 페이지에서 읽은 값만 적었다. 못 읽은 것은 "미확인". 저장소는 읽기만 했고 고치지 않았다.

1. **three.js CSS2DRenderer + Sprite/SpriteMaterial 예제** — 테라·헨리. 결정 5·16·33(헨리 로드맵 "빌보드 열다섯 + 도형·텍스처 건물"). 그리기 층 150줄 교체의 두 축: 인물은 Sprite 빌보드, 말풍선·이름표는 지금 DOM 그대로 CSS2DObject 에 얹는다. MapControls 는 같은 릴리스(r186) 안에 있으니 셋을 한 번에 본다.

3. **claudecodeui tools/ README** — 테라. 결정 30(도구 줄 덤핑 → 한 줄로 접기)·28-①(방 헤더 "지금: ○○가 △△ 하는 중"). '도구 이름 → 표시 방식' 설정표 + 한 줄/접기 두 렌더러 + 연속 호출 그룹 묶기. AGPL 이라 구조만 읽고 app.js 에 새로 쓴다.
