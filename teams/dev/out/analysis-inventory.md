# 분석 탭 — 지금 그리는 것 전부 (대표가 고르는 목록, 결정 24)

2026-09-13 · R23 · 쓴 사람 테라. 읽는 사람: 대표(고른다) · 레오.
근거: `server/public/app.js renderAnalysis`(1668~1784행, 이 커밋 기준)와 `/api/analysis`(`server/index.mjs`). 눈으로 본 게 아니라 코드에서 뽑았다 — 그리는 항목은 아래 다섯 묶음 열하나가 전부다(세어 봤다).

대표 원문(결정 24): "분석쪽 탭에 구성해놓은 내용, 배치도 다 쓸모없는 내용만 배치되어있고, 보기도 어렵고".
처리 규칙: 대표가 쓰는 질문 셋 — **누가 뭘 했나 · 뭐가 막혔나 · 돈/시간이 어디 갔나** — 에 답하는 것만 남긴다. 대표가 이 표에서 **남길 것에 ○** 를 치면 그 항목만 다시 배치하고, 나머지는 뺀다. 아무것도 안 고르시면 탭을 없앤다.

## 없는 것 — 세 질문에 필요한데 지금 안 그리는 것

| 질문 | 없는 것 | 있으면 어디서 |
| --- | --- | --- |
| 돈/시간이 어디 갔나 | **비용** — 자리별·라운드별 토큰/달러. 지금 시스템은 비용을 어디에도 안 센다 | claude 세션 `result` 메시지에 usage 가 온다(`server/session.mjs` 가 지금은 버린다) · codex 는 stdout 에 없음. 세는 것 자체가 M7(비용 상한)과 같은 자리 |
| 돈/시간이 어디 갔나 | **시간** — 라운드가 몇 시간 걸렸나, 자리별 턴 시간 | `rounds.jsonl` 의 startedAt·endedAt(있음, 안 그림) · 세션 턴 시작/끝(있음) |
| 뭐가 막혔나 | **막힌 이유 한 줄** — FAIL 이 왜 났나, 승인이 어디서 기다리나 | 판정 카드 본문 첫 줄 · 승인 큐 `pending` · 상황판 `blocked` |
| 누가 뭘 했나 | **자리별 산출물** — 누가 어느 파일을 냈나 | `out/` 파일에는 지은이가 없다 — 커밋 로그나 발언의 경로 링크에서 거꾸로 |

## 제안 (테라, 대표가 고른 뒤에만)

세 질문 그대로 세 칸: **누가 뭘 했나**(6 라운드 이력 + 11 산출물, 자리 이름 붙여서) · **뭐가 막혔나**(2 의 FAIL·REVISE 를 이유 한 줄과 함께 + 승인 대기) · **돈/시간**(라운드 시간부터 — 비용은 M7 에서 세기 시작하면 그때). 1·4·7·8·9·10 은 뺀다.
이건 제안이고, 어느 것을 남기는지는 대표가 이 표에 표시한 대로 간다.
