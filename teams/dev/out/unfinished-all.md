## 대표님이 화면에서 바로 보실 것

1. **경영팀 이름은 바뀌었는데 사람이 비어 있다** — 유진·노라·빅터 이름만 들어갔고 세 사람이 읽을 성격 파일이 없다. 유진·빅터는 통째로 비었고 노라는 이름 없는 공용 감사역 글이다. **게다가 이름 바꾼 것이 아직 저장(커밋)도 안 됐다.** → 경영·총괄 / 작음
2. **화면 말이 아직 어렵다** — 판정 도장은 PASS·REVISE 그대로, 방 머리는 R28, 옆에 DESTINATION·CUT LIST 가 영어로 뜬다. 마케팅 말 사전 대기. → 마케팅 먼저 / 작음
3. **방이 멈춰 보이는 진짜 원인** — **서버를 다시 켜면 기다리던 차례가 사라진다.** 대표가 본 "마케팅 방이 멈췄다" 가 이것이다. → 개발 / 큼
4. **마을 탭이 아직 옛 평면 그림** — 부품 107개는 들어왔고 지금 작업 중. → 개발 / 큼
5. **대표가 누를 버튼이 없다** — 실무가 "어느 쪽으로 할까요" 물으면 글로만 올라온다. → 개발 / 작음
6. **분석 탭이 손도 안 댄 채** — 열한 가지 중 남길 것을 대표가 골라야 한다. → 총괄→개발 / 큼
7. **관제탑·보고서 화면 새로 짜기 통째로** — "알림이 읽기 어렵다" 도 여기 묶인다(M6). → 개발 / 큼
8. **저녁·주말 화면이 집으로 보내는 것뿐** — 아침 계획 자리도 산책 자리도 없다. → 개발 / 큼
9. **팀끼리 요청은 되는데 하루 보고가 없다** — 마일스톤 끝날 때 "부족한 것" 자동 정리도 없다. → 개발 / 큼
10. **로드맵을 바꿔도 열린 회의 제목이 안 따라온다** — 지금 맞아 보이는 건 사람이 손으로 고친 것. → 개발 / 작음
11. **아침 보고서가 아직 한 번도 안 돌았다** — 내일 9시가 첫 회. → 총괄 / 작음
12. **성격 초안 17장이 아직 방에 안 꽂혔다** — 다 썼는데 실제 방 파일로 안 옮겨졌다. 작업 중. → 마케팅 / 큼
13. **방에 그림을 직접 못 올린다** — 경로를 글로 적는 방식뿐. → 개발 / 큼
