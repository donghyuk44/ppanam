# 떠 있는 세라 — 만드는 방법 한 장 (M7, 결정 87·88·89)

솔라, 2026-09-14 새벽. 대표가 자기 전 마지막으로 남긴 것 — "아침에 세라가 반겨주면 좋겠다."
아래 순서대로 갔고, 어디까지 갔는지는 이 파일과 방에 그대로 남긴다.

## 뭘 만드는가

**별개 맥 앱** (결정 88) — 세라는 새 AI 가 아니다. 이미 사는 총괄실 세션을 그대로 쓰고,
이 앱은 그 상태를 **보여주고 말 걸어 주는 창**이다. 머리를 두 번 만들지 않는다.

## 왜 Tauri 인가

| | Tauri | Electron |
| --- | --- | --- |
| 배포 크기 | 수 MB (OS 웹뷰 재사용) | ~100MB+ (Chromium 통째로 번들) |
| 투명 창·항상 위 | `transparent: true` · `alwaysOnTop: true` — 둘 다 기본 옵션 | 같은 옵션 있음, 무겁게 뜬다 |
| 맥 클릭-스루(배경 클릭 통과) | `setIgnoreCursorEvents` 있음 | 있음 |
| 이 저장소와 궁합 | 화면은 그냥 HTML/CSS/JS — server/public 에 있는 것 그대로 웹뷰에 얹으면 됨 | 같음, 다만 무겁다 |

떠 있는 캐릭터 하나 + 알약 막대라는 화면 크기를 생각하면 Electron 의 무게를 감당할 이유가 없다.
**Tauri 로 간다.**

## 서버에 어떻게 붙나 (결정 88·89 — MCP 아님, 직접 붙는다)

이미 뚫려 있는 길 그대로 쓴다. 관제탑 브라우저가 쓰는 것과 같은 문이다.

- 상태: `GET /api/boot` (`server/index.mjs:203`)
- 말 걸기: `POST /api/say` (`server/index.mjs:337`)
- 실시간: `ws://localhost:4321/ws` (`server/index.mjs:496`)

앱 안 웹뷰가 이 세 개만 쓰면 된다 — 새 서버 코드도, 새 계약도 필요 없다.
붙는 주소는 `localhost:4321` 고정(결정 — 이 세계는 한 맥 안에서만 돈다, Tailscale 결정 유지).

## 창 동작 (대표가 보낸 그림 기준)

- 투명 배경, 캐릭터 하나(그림은 디자인/하영, 인형 서울 재질 — 결정 86)
- 아래 알약 막대: 고치기·소리·알림 배지 아이콘 셋
- 늘 위 (`alwaysOnTop`), 끌어서 옮길 수 있게 (`data-tauri-drag-region`)
- 눌러 확장하면 말풍선/입력창 — `/api/say` 로 방에 전하고 ws 로 답을 받음

## 순서와 오늘 밤 간 곳

① 이 문서 — **끝, 여기까지 확정**
② 창이 뜬다 (투명 배경 + 자리표시 원 하나, 그림 없이) — **뼈대 커밋됨** (`sera-app/`): `index.html`·`app.js`·`style.css` (자리표시 원, 알약 막대, `/api/boot` 폴링·`/api/say`·`/ws` 연결 — 서버 계약 그대로) + `src-tauri/`(Cargo.toml·tauri.conf.json·main.rs, `transparent`+`alwaysOnTop`). **이 세션엔 `cargo` 가 없어 한 번도 빌드해 본 적이 없다** — 첫 빌드 확인은 대표 맥에서(`sera-app/README.md` 순서). JS 는 `node --check` 로 문법만 확인함
③ 살아 있다 (눈 깜빡임) — 그림 온 뒤
④ 알린다 (배지) — ws 로 `/api/boot` pending 개수 구독
⑤ 말을 건다 (`/api/say` 왕복) — 뼈대는 ②③ 뒤에 얹기만 하면 됨

②부터는 실물 창을 띄워 눈으로 봐야 하는데 이 세션은 GUI 를 못 띄운다 —
Tauri 프로젝트 뼈대(`src-tauri/`, `tauri.conf.json`)와 최소 HTML 은 코드로 만들어 커밋할 수 있지만,
**실제로 macOS 에서 창이 뜨는지는 대표 맥에서 `npm run tauri dev` 로 봐야 확인된다.**
그림(캐릭터 png)은 디자인 M4·결정 86② 대기 — 오기 전까진 자리표시 원으로 세운다.
