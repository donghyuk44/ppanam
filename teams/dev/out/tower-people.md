## ① 데이터 — `summaries[팀].people` (계약: `docs/event-schema.md` 3절 "사람별 집계")

- `bus/bus.mjs peopleOf(log, cast, { now })` — 대화록만 보는 순수 함수. 자리마다 `lastSaidAt · doing · todaySay · todayVerdict · bossCall`.
  뒤에서 앞으로 훑고, 오늘 밖 + 라운드 밖 + 모두의 마지막 발언을 찾았으면 멈춘다. `(패스)` 는 발언이 아니다.
- `server/index.mjs summaryOf → peopleOf(team, sessions, conductor)` 가 얹는 것: claude 자리 `busy·lastSignal` = `session.statusAll`,
  codex 자리 `busy` = 사회자 `snapshot(team).outsideBusy`, `lastSignal` = 마지막 발언 시각(스트림이 없다), `journalFirst` = `session.journalFirstSentence`
  (파일 mtime 캐시를 붙였다 — 250ms 마다 열다섯 파일을 읽지 않게).
- `people.boss` = `{ lastSaidAt, lastText, todaySay, todayDecisions }`. 한 방 값이다 — 화면이 다섯 방을 합친다.
- `todayVerdict` 는 `review`·`outside` 만 숫자, 나머지 null(화면이 항목을 안 그린다). 제리(hq outside)는 판정을 안 내니 늘 0 으로 보인다 — 알고 둔 것.
- 덤 `summaries[팀].bossNotes[]` — 오늘 대표를 부른 발언 30건, `ask`(물음표·정해 주세요·골라·답해) 표시. "전체" 탭의 오늘 보고 줄이 `ask` 아닌 것을 그린다.
  종 배지는 아직 이 구분을 안 쓴다(M4 결정 52).
- "오늘" 은 서버 프로세스의 현지 날짜. 기존 `approvals.passedToday` 가 UTC 날짜(`toISOString().slice(0,10)`)를 쓰는 건 그대로 뒀다 — 다른 건이라 안 건드림. 자정~09:00 사이엔 둘이 다른 날을 본다. 적어만 둔다.

## ②③ 화면 — `server/public/index.html · app.js · style.css`

- 탭 줄 `.tabs` 넷: 전체 / 팀 / 개인 / 요청. 마지막 탭 `localStorage ppanam.towerTab`, 처음은 **전체**(결정 50). 버튼 높이 36.
  작은 숫자: 팀 = 대표 차례인 팀 수, 개인 = 대표를 부른 사람 수, 0 이면 없음.
- **전체**: 타일 셋(대표 차례 · 승인 대기 · 요청 진행/완료 `— / —` M3 전) → 대표 차례 목록(막힌 방·부른 방·C 카드, 누르면 그 방) → 팀 다섯 한 줄(이름 · 알약 · R/마일스톤 · 작업 중 이름 · 승인 대기) → 오늘 보고(팀 · 이름 · 시각 · 첫 160자, 누르면 그 발언).
- **팀**: 지금 카드 다섯 그대로(`renderTowerTeams`). 헨리 2절의 줄 순서 고정·팀원 칩 줄은 2판(하영 목록) 뒤에.
- **개인**: 대표 카드 맨 위(`--me-line` 테두리, `자리에`/`자리 비움` = 마지막 지시 10분 안, 2줄 마지막 지시 첫 줄, 3줄 `오늘 지시 n · 결정 n`) → 팀별 `details` 묶음(`디자인 3`, 접힘 기억 `ppanam.towerGroup.<팀>`, 부른 사람 있으면 빨간 점) → 사람 카드 다섯 줄:
  1 칩 26 + 이름 13.5/500 + 자리(role 의 ` · ` 앞) + 알약 / 2 하는 일(도구 줄이면 `toolPhrase`, 아니면 마지막 발언 첫 문장, 잠이면 —) / 3 `신호 N분 전 · 오늘 발언 n · 판정 n`(감사만) / 4 `대표 불렀음 · N분 전 · "첫 40자"`(답 없을 때만, 누르면 그 발언) / 5 `「일지 첫 문장」`(누르면 `/api/actor` 의 문단 전체, 한 번 읽으면 둔다).
  알약 순서: 일하는 중 → 대표 부름 → 막힘(방 phase blocked) → 잠(마을 시계 night·rest) → 대기. 색은 셋(--bad / --live / --ink-4) — 헨리 6절.
- **요청**: 빈 문구 한 줄. M3 승인 체인 데이터가 오면 채운다.
- 폰(≤819): 탭 버튼이 폭을 나눠 갖고, 묶음 머리 `sticky`, 타일 글자 19px. 카드는 한 열(격자 `minmax(300px)` 에 388px 이면 자동 한 열).
- 마을 시계 `world` 방송을 받으면 mode 가 바뀔 때만 개인 탭을 다시 그린다.
