## 1. 받을 것 넷 (근거)
- **1-1 화면은 칸만, 제목 30자·요약 60자, 넘으면 다시 쓰게** — 받는다. 실측으로 폭탄은 화면이 아니라 자료에 있다: 보드 129건 이름 평균 43자·최대 161자·60자 넘는 것 14건, 요청 83건 첫 줄 중간 53자·최대 560자, 순서 목록은 줄의 8~9할이 80자 넘음(dev 12/15·design 11/13·marketing 14/16·finance 16/19·hq 14/17). 자는 화면(bossOk 60자, 숨김)이 아니라 **쓰는 순간**(보드·요청 도구)에 재고 되돌려야 한다 — 숨기면 대표가 못 읽고, 되돌리면 쓴 사람이 고친다. 이게 오늘 팀 카드 "없음" 병의 뿌리와 같다.
- **2-① 프로젝트 행 + 단계 3~5, 이전 단계 PASS 뒤에만 착수** — 받는다. 주제 9 셋 동의(단계 셋~다섯, 끝 조건 = 결과물 파일, 작업당 시도 셋)와 같다. 새로 필요한 건 칸뿐: 프로젝트·단계 n/N·시작·끝·결과물·제목/요약 분리 — 지금 보드 칸 13개(id·what·team·seat·owner·status·importance·urgency·after·bottleneck·milestone·note·stream)에 그 여섯이 없다 → J24 한 커밋(솔라).
- **2-② 요청 행(연관 프로젝트·발신➔수신 배지·한 줄 60자·결과물 칩)** — 받는다. 요청 파일에 from·to·what·why·approval 은 있고 project 와 결과물 칸이 없다. "자동 매핑"은 요청이 매달린 승인 카드 → 보드 항목 → 프로젝트로 셀 수 있다(칸이 생기면).

## 2. 고쳐야 할 것 일곱 (비판)
1. **1-2 "즉시 차단" ↔ 2-④ "점등"이 서로 다르다.** 차단은 위험하다 — 오늘 실측: 한 회차에 한 사람이 같은 코드 파일을 49번 읽었는데, 훅이 어디를 읽었는지(앞부분·뒷부분)를 안 남겨 부분 읽기와 되풀이를 구분 못 한다. 첫 판은 **경고 배지만**, 차단은 훅이 부분 읽기를 남긴 뒤 대표가 정한다.
2. **반복 읽기 문턱 "3회"** — 코드 파일은 나눠 읽는 게 정상이라 3회는 거의 모두에게 켜진다(오늘 개발 두 사람 다). 문턱은 "한 회차에 같은 파일 **통째** 읽기 3회"로, 훅 고침 뒤.
3. **상태 다섯(진행·막힘·검수 대기·PASS·FAIL)에 "대기"가 없다.** 스트립의 "큐 N건"은 대기 항목 수라 상태값이 있어야 센다 → 여섯째 값 대기(행에 배지 없이 스트립 수로만). FAIL 은 결과가 아니라 **머무는 상태**(CLAUDE.md "FAIL 이 나오면 멈춘다" — 대표께 보고 전엔 못 움직임). "안 함"은 목록 밖.
4. **4 폴더 여섯을 실제 폴더로** — 오늘 10:3x 대표 답이 이미 있다: "목차 한 장으로 여섯 묶음"(폴더 이름은 코드 220곳 넘게 박혀 있음). 명세 4절은 **색인 한 장의 여섯 묶음**(J23)으로 받고 실제 폴더는 그대로. CS 는 안젤 자리(사용성 검수)로 시작.
5. **3 대시보드 안의 탭 넷 ↔ 오늘 14:24 정하신 상단 탭 구조.** 명세의 탭 넷은 새 화면이 아니라 있는 탭의 다시 묶기다(관제 = 상황판+보드 · 요청 흐름 = 요청 탭 · 그래프 = 예정 J4 · 성과 = 리포트). 둘 다 두면 같은 것이 두 곳에 뜬다 → 대시보드 한 장은 **숫자 넷 + 스트립 + 프로젝트 표까지**, 나머지 셋은 제 탭 그대로 — 대표 결정.
6. **낱말** — 명세는 영어·업계 말(드로어·KPI·큐·라우팅·스텝 게이트·앵커)이고 오늘 대표 규칙(216: 표준 제품 낱말, 10살도)과 맞선다. 붙여 넣으신 글의 낱말 넷 뒤집기(정할 것→승인 대기 · 막힌 것→블로커 · 아침 한 장→데일리 리포트 · 자리 비움→오프라인)도 "오류 있음" 글 안에 있어 **살릴지 여쭐 것**. 배지 글자는 화면 글자라 하영 사전 한 줄씩(PASS·FAIL 은 CLAUDE.md 에 이미 있는 낱말이라 받음).
7. **2-① 소모 토큰(프로젝트마다)** — 사용량 기록에 프로젝트 칸이 없다(자리·회차·세션만). 프로젝트 칸(J24)이 먼저고, 그 전엔 "오늘 소모 토큰" 합계만 가능. 경과 시간도 시작·끝 칸 뒤(지금 0건).
