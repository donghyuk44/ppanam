# 일일보고서 · 주간계획서

대표가 아침에 읽는 곳 (결정 80).

- `YYYY-MM-DD.md` — 일일보고서. 매일 아침 9시. 톰이 쓰고 독립검수가 사실 확인
- `YYYY-MM-DD-주간.md` — 주간계획서. 월요일에만

**맨 위에 오는 것**: "대표님 대신 정한 것" — 밤새 톰·제리가 대리로 정한 것(결정 85·90). 대표가 보고 뒤집을 수 있게. FAIL 을 푼 것은 다른 것과 섞지 말고 따로 눈에 띄게.
원본은 `teams/hq/out/proxy-decisions.md` 와 방 대화록의 "대리 결정" 줄 둘 다 — **파일이 비어 있어도 대화록에서 긁는다**(결정 85 ③).

**담는 것**: 어젯밤 사이 있었던 일(팀마다 한 줄) · 오늘 대표님 차례(없으면 "없습니다") · 오늘 각 방이 할 일(`teams/<팀>/progress.json` 의 "다음") · 톰의 한마디 · 어제 나온 그림.

**쓰는 규칙**: 폰에서 30초. 쉬운 한국어. 확인 안 한 숫자는 쓰지 않는다. **조용한 날은 짧게 끝낸다** — 분량을 채우려 늘리지 않는다.

**시각 주의**(결정 101): 방 기록의 `ts` 는 세계표준시라 우리 시각과 아홉 시간 차이가 난다. "어젯밤" 을 셀 때 날짜가 하루 밀리지 않게 우리 시각으로 바꿔서 센다.
