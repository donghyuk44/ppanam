주제 0 — 일의 연결과 순서, 중요·긴급 표 — 셋의 안 (2026-09-18)

대표 원문(비서실 12:02): "0. 현재 요청받아 배치된 모든 작업의 연결관계 및 우선순위에 대한 판단 및 조정 (필요/불필요/지연요소 등) --> 이거 중요도와 긴급도로 구분하면 분류 쉬움 [ 매우중요, 보통중요, 중요하지 않음] [긴급 / 보통 / 여유] -> 아이젠하워 매트릭스 구조" (승인 없이 셋이 정해 적용).

3판(12:1x, 나래) — 세라 1판(3bb62fd, 디자인·개발 47건)에 마케팅·경영·총괄·비서실 22건을 더한 2판을 세라 공격 셋으로 고침. 나리 공격 뒤 4판이 정본.

0. 배운 것 — 링크 둘 (나래가 읽음)

  • Asana 한국어 글(2026-07-09): "아이젠하워 매트릭스란 긴급성과 중요도라는 두 가지 기준으로 업무를 네 개의 사분면에 분류하여 … 해야 할 일, 계획해야 할 일, 다른 사람에게 위임할 일, 하지 않아도 될 일의 네 가지 카테고리로". 아이젠하워 원문 인용: "긴급한 것은 중요하지 않고, 중요한 것은 절대 긴급하지 않습니다".
  • 네이버 블로그(예스폼, 2025-10-24): "업무를 긴급도·중요도 기준으로 4분면(즉시 수행·일정 계획·위임·제거)으로 분류해 우선순위를 한눈에 정리".
  • 우리에 맞춘 것: 대표는 칸을 셋×셋으로 주셨다 — 네 칸의 행동(즉시·계획·위임·삭제)을 우리 말로 옮기면 지금 한다·순서대로·남에게 넘기거나 작게 자른다·안 함. "위임"은 우리 말로 "다른 감사가 대신"·"작게 자른다"다.

1. 잣대 — 우리 말로 (배운 것 → 우리에 맞춘 것)

아이젠하워 표는 "중요한가"와 "급한가"를 따로 묻고 네 칸으로 나눈다. 우리 칸의 뜻:

긴급 (누가 기다린다 · 대표가 "지금")보통 (순서가 있다)여유 (뒤에 해도 아무도 안 기다린다)
매우 중요 — 대표 원문에서 바로 나왔고 이번 달성 목표("무엇을 끝냈고 → 무엇이 나왔고 → 지금 무엇으로 이어지나를 화면만 보고 안다")에 닿는다지금 한다(한 사람 하나)순서를 정해 한다(여기 오는 일은 거의 없다)
보통 중요 — 규칙·도구·화면 정리, 대표 원문이 있으나 목표 앞줄은 아님남에게 넘기거나 작게 자른다순서 뒤접수 목록에 두고 회의 때 다시 봄
중요하지 않음 — 대표 원문 없음·컷리스트 근처·이미 다른 것으로 갈음됨(없어야 정상)"안 함" 후보"안 함" 으로 닫는다
  • "필요/불필요"는 셋째 줄이다 — 중요하지 않음은 보드에 "안 함"으로 적어 잊힘 목록에서 뺀다.
  • "지연 요소"는 연결에서 나온다 — 어떤 일이 끝나야 시작되는지(2절). 지연 요소가 있는 일은 긴급 칸에 못 간다(기다리는 게 있으면 지금 못 하니까).

2. 연결 — 무엇이 무엇을 기다리나 (디자인·개발, 파일로 셈)

  1. 솔라 아침 한 장 여섯 → 경영 4단계 닫힘(유진 재기 → 노라 30초 → 빅터) → 경영 다음(도서관).
  2. 테라 프로필 카드·이름표 두 사람(대표 "지금") → 헨리 "같다" → 대표께 사진.
  3. 책임자·시작·끝·결과물 칸(계획 6, 솔라·톰) → 타임라인에 내용이 생김 → 그래프 보기(J4 자료 → J8 시안 → 화면). 이게 없으면 타임라인 화면(J2)은 껍데기.
  4. 하영 낱말 표(스물여섯·규정집) → 테라·솔라 216 자 → 화면 글자 넷.
  5. 제리 답 → 계획표 11단계 → 채팅 기능 여덟(C9~C17) 시작. 첨부 셋은 C17에 얹힘.
  6. 레오 감사 대기 13(T2·T3·T4·C5·C6·C7·D1·D3·J1·K1·K3·K4·O1) → 닫혀야 테라·솔라 "끝난 것"이 센다. 지금 코덱스 한도라 제미나이, 부름 두 번 뒤 다른 감사.

연결 — 마케팅·경영·총괄·비서실(나래, 파일로 셈)

  1. 하영 규정집 1판·스물여섯 표(J10) → 테라·솔라 자(216) → 화면 글자 넷 → 안젤 사용성(X1).
  2. 솔라 아침 한 장 여섯(재시작 11:5x 됨) → 유진 F3 첫 실물 검수 → 노라 12살 30초 → 빅터 판정 → 경영 4단계 닫힘 → J21 도서관 셋(색인 다시·사서 실측·책장) → J14 책장 셋으로.
  3. 톰 J18 보드 정본(오늘) → 순서 목록 여섯 → 회의 점검표(회의 세 번) → J19 주간 계획서는 회의 파일로 갈음 후보.
  4. 톰이 다니엘·빅터·제리를 이름으로 부름 → H1·F1·F2 감사 대기 셋 닫힘(부름 두 번 뒤 다른 감사).

4. 조정 제안 (셋이 동의하면 톰이 보드에)

  • "안 함" 후보 다섯은 낸 사람(헨리·테라·솔라)에게 한 글자 — 한다/안 함.
