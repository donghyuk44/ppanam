## 1. 틀 — 세 칸, 팀당 한 줄

```
# 아침 한 장 — <날짜>
<요일> <만든 시각> 기준 · 서버가 상황판에서 만듦        ← 시각은 만든 그때(예 "수요일 오후 5시 10분 기준"), 정해 둔 시각 없음

## 대표님 대신 정한 것          ← 지난 장 뒤 대리 결정이 있을 때만(결정 85 ③). 없으면 절 자체가 없다
- <누가> · <무엇을 정했어요>
되돌리시려면 방에 한마디.

## 된 것
- <사람> · <무엇>                ← 팀당 한 줄, 없으면 "<팀> · 어제는 낸 게 없어요"

## 막힌 것 <N>                   ← N = 줄 수. 0이면 "## 막힌 것 0" 한 줄만
- <팀> · <무엇이> <왜 멈췄어요> — <누가> <무엇을 해야 풀려요>

## 대표님이 하실 일 <N>          ← N = 줄 수. 0이면 "## 대표님이 하실 일 0 — 오늘은 없어요" (3판: "대표님 손" 은 대표님이 금한 말 — 나리 19:0x)
- <팀> · <대표님이 할 동작 하나>
```

절 이름 넷은 `grep '^## '` 로 재는 잣대라 글자 그대로. 순서 고정: 대리 결정(조건부) → 된 것 → 막힌 것 → 대표님이 하실 일. 머리 숫자는 막힌 것·대표님이 하실 일 둘, 기준값 0.

## 4. 줄을 만드는 사람이 외울 것 (하영 꼴 셋 + 하나)

- **된 것** = `{사람} · {무엇}` — 종류(그림·글·표·코드·허락)가 보이게
- **막힌 것** = `{팀} · {무엇이} {왜 멈췄어요} — {누가} {무엇을 해야 풀려요}` — 풀리면 지운다
- **대표님이 하실 일** = `{팀} · {대표님이 할 동작 하나}` — 지금 할 수 없는 건 안 올린다
- **대리 결정** = `{정한 사람} · {무엇을 정했어요}` — 되돌릴 수 있게 한 줄에 하나
