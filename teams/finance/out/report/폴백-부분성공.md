# A2 — cast.json 폴백 값(gemini↔codex)과 부분 성공 규칙

글 노라. 2026-09-16, 라운드 6. 나리 배분(경영 A2). 재료: 다섯 팀 `cast.json` · `bus/bus.mjs` · `bus/outside.mjs` · `state/infra.json` · `teams/dev/decisions.md` · `teams/dev/roadmap.json`.

## 1. 폴백 값 — 지금 실제로 적혀 있는 것

다섯 팀 `outside` 자리(제리·레오·마크·다니엘·빅터) 전부 `"model": "gemini"`, `fallback` 키는 다섯 다 **없음**(`grep -rn "fallback" teams/*/cast.json` 0줄). CLAUDE.md 가 말하는 "외부감사는 codex" 는 기본값이 아니라 원래 자리이고, 지금은 결정 118·122(교체 사유)로 다섯 다 gemini 가 대신 앉아 있다.

`fallback` 이 안 적혀 있으면 `bus.mjs` 925행 `fallbackOf` 가 기본을 만든다: `model:'gpt'` 면 `'gemini'`, `model:'gemini'` 면 `'gpt'`. 지금은 다섯 다 `model:'gemini'` 라 계산값은 **'gpt'(codex)** 다 — 그런데 이 계산값을 실제로 쓰는 자리는 `bus/outside.mjs` 394행 딱 한 곳뿐이고, 그 코드는 389행 `let KIND = engineKindOf(team)` 이 `'gpt'` 일 때만 도는 쿨다운 분기(392행 `KIND !== 'gpt' ? null : outsideCooldown()`) 안에 있다. 지금 다섯 팀은 시작부터 `KIND==='gemini'` 라 이 분기 자체가 안 돈다 — **gemini 가 이유 없이 실패해도 codex 로 자동으로 안 넘어간다.** `fallbackOf` 가 계산은 하지만 아무도 안 물어본다.

`state/infra.json` 의 codex 값: "계정 사용 한도 — 2026-09-20T15:38 까지 · gemini(agy) 가 대신 돈다." 되돌림은 사람 손이다(decisions.md 362행 "되돌림은 대표 버튼") — cast.json 의 `model` 을 다시 `'gpt'` 로 바꿔야 하는데, 이건 지금 어디에도 예약돼 있지 않다. **09-20 이 지나도 아무것도 자동으로 안 바뀐다.**

## 2. 부분 성공 규칙 — 언제 회차는 닫고 단계는 안 닫나

**회차(라운드) 닫힘** — `bus.mjs` 1388~1391행: outside 자리가 다른 회사 엔진(`isForeign`)이고 `suspended` 가 아니면 그 라운드에 outside 의 PASS 카드가 반드시 있어야 한다. 내부감사(review/guide)만으로는 못 닫는다. 대신 outside 를 `suspended:'<날짜>'` 로 적으면(결정 118 ②, `round.mjs` 963행 예시) 라운드는 닫히되 `rounds.jsonl` 에 `outsideAudited:false`·`outsideWhy:'suspended'` 가 박힌다(`bus.mjs` 1530·1548행) — codex 가 09-20 에 돌아오면 이 표시가 박힌 것만 다시 본다(`bus.mjs` 1520행 주석).

**단계(마일스톤) 닫힘** — 지금까지는 그 단계의 마지막 라운드가 PASS 로 닫히면 로드맵에 자동으로 `pass` 가 찍혔다(`bus.mjs` 1556행, 외부 감사가 없으면 문구에 "(외부 감사 없이 — 이유)" 만 덧붙고 그래도 닫힌다). **그런데 결정 137(오늘, decisions.md 402행)로 이게 더 이상 전부가 아니다**: "감사 PASS + 나리 사용성 검사(412 와 1280) + 시안이 있는 화면은 헨리 '같다' — **셋이 다 있어야 단계가 닫힌다**." 지금 로드맵(`teams/dev/roadmap.json` n=10, status `"now"`)에 그대로 박혀 있다: "닫힘 = 자 0줄 + 나리 30초(412·1280) + 헨리 같다 + 레오 떨어뜨릴 이유 셋."

회차 닫힘은 사실 셋이다(`bus.mjs` 1380~1391행 `endRefusal`) — 마지막 판정 카드가 PASS · 그 뒤 사회자의 "판정 완료" note(`meta.verdictFlow==='pass'`) · outside 자리가 다른 회사 엔진이고 suspended 아니면 그 outside 의 PASS 카드까지, 셋 다 있어야 라운드가 닫힌다("레오 PASS 하나로" 가 아니다 — 유진 감사-A2 #1).

단계는 회차보다 저절로 안 남는다 — `bus.mjs` 1553~1556행은 `end -v PASS` 면 그 즉시 무조건 로드맵에 `pass` 를 찍는다. 결정 137의 세 관문은 **글**이지 이 코드에 배선돼 있지 않다. 그래서 지금은 그 단계를 열어 두려면 실무가 나리 검사·헨리 확인이 끝나기 전엔 **`-v PASS` 를 안 붙이고 닫아야** 한다(`round.mjs end --summary`, 판정 카드는 PASS 여도 `rounds.jsonl` verdict 는 null로 남는 길) — "로드맵에서 `now` 그대로 남는다" 는 저절로 되는 게 아니라 실무가 그렇게 닫아야 남는다(유진 감사-A2 #2, R5 실측). 이게 지금 이 경영팀이 겪은 것과 같은 자리다(결정 137을 F1 감사에서 이미 짚었다, `teams/finance/out/report/감사-F1-노라.md` #2).

## 3. 배선(솔라 몫)에 넘길 것 — 글만, 코드는 안 짠다

- gemini 자체가 실패할 때 codex 로 자동 전환하는 분기가 없다 — `outside.mjs` 389~410행 쿨다운 로직을 `KIND==='gpt'` 전용이 아니라 넓혀야 폴백이 실제로 도는데, 그냥 넓히면 안 된다 — 지금 gemini 의 폴백 값은 codex 이고 codex 는 09-20 까지 한도(`state/infra.json`)라, 확인 없이 부르면 한도 걸린 엔진을 또 두드리게 된다. 넓히는 글: "폴백이 gpt 면 `outsideCooldown()` 을 먼저 보고, 쿨다운이면 대표께 올리고 건너뛴다(지금 392~409행이 gpt 자리에 하는 것과 같은 모양)". 이건 코드라 솔라 몫.
- 09-20 codex 복귀를 사람이 기억해야 한다 — 자동 알림이나 체크 없음.
- 단계 닫힘에 나리 검사·헨리 "같다" 가 로드맵 파일에 필드로 안 박혀 있고 지금은 글(deliverable 문장)로만 있다 — 서버가 이 셋을 따로 추적하려면 구조가 필요하다(지금은 사람이 결정 137 문구를 매번 다시 읽는다).
