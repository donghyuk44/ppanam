# 주제 0 — 일의 연결과 순서, 중요·긴급 표 — 세라 안 (2026-09-18 12:0x, 1판 — 셋의 공격 전)

대표 원문(비서실 12:02): "0. 현재 요청받아 배치된 모든 작업의 연결관계 및 우선순위에 대한 판단 및 조정 (필요/불필요/지연요소 등) --> 이거 중요도와 긴급도로 구분하면 분류 쉬움 [매우중요, 보통중요, 중요하지 않음] [긴급 / 보통 / 여유] -> 아이젠하워 매트릭스 구조" · "모든 결론에 도달하고는 방법을 너희가 알아서 적용해서 관리해, 내 승인 필요없어"
참고 링크 둘(asana 아이젠하워 · 네이버 블로그)은 나래가 크롬 원격 창으로 읽고 인용 한 줄씩 — 저는 웹을 못 봄(안 본 것).

## 1. 잣대 — 우리 말로 (배운 것 → 우리에 맞춘 것)
아이젠하워 표는 "중요한가"와 "급한가"를 따로 묻고 네 칸으로 나눈다. 우리 칸의 뜻:

| | 긴급 (누가 기다린다 · 대표가 "지금") | 보통 (순서가 있다) | 여유 (뒤에 해도 아무도 안 기다린다) |
|---|---|---|---|
| **매우 중요** — 대표 원문에서 바로 나왔고 이번 달성 목표("무엇을 끝냈고 → 무엇이 나왔고 → 지금 무엇으로 이어지나를 화면만 보고 안다")에 닿는다 | **지금 한다**(한 사람 하나) | **순서를 정해 한다** | (여기 오는 일은 거의 없다) |
| **보통 중요** — 규칙·도구·화면 정리, 대표 원문이 있으나 목표 앞줄은 아님 | **남에게 넘기거나 작게 자른다** | 순서 뒤 | 접수 목록에 두고 회의 때 다시 봄 |
| **중요하지 않음** — 대표 원문 없음·컷리스트 근처·이미 다른 것으로 갈음됨 | (없어야 정상) | "안 함" 후보 | **"안 함"** 으로 닫는다 |

- "필요/불필요"는 셋째 줄이다 — 중요하지 않음은 보드에 "안 함"으로 적어 잊힘 목록에서 뺀다.
- "지연 요소"는 연결에서 나온다 — 어떤 일이 끝나야 시작되는지(2절). 지연 요소가 있는 일은 긴급 칸에 못 간다(기다리는 게 있으면 지금 못 하니까).

## 2. 연결 — 무엇이 무엇을 기다리나 (디자인·개발, 파일로 셈)
1. 솔라 **아침 한 장 여섯** → 경영 4단계 닫힘(유진 재기 → 노라 30초 → 빅터) → 경영 다음(도서관).
2. 테라 **프로필 카드·이름표 두 사람**(대표 "지금") → 헨리 "같다" → 대표께 사진.
3. **책임자·시작·끝·결과물 칸**(계획 6, 솔라·톰) → 타임라인에 내용이 생김 → 그래프 보기(J4 자료 → J8 시안 → 화면). 이게 없으면 타임라인 화면(J2)은 껍데기.
4. 하영 **낱말 표(스물여섯·규정집)** → 테라·솔라 216 자 → 화면 글자 넷.
5. 제리 답 → 계획표 11단계 → **채팅 기능 여덟**(C9~C17) 시작. 첨부 셋은 C17에 얹힘.
6. 레오 **감사 대기 13**(T2·T3·T4·C5·C6·C7·D1·D3·J1·K1·K3·K4·O1) → 닫혀야 테라·솔라 "끝난 것"이 센다. 지금 코덱스 한도라 제미나이, 부름 두 번 뒤 다른 감사.

## 3. 표 — 디자인·개발 열린 것 (통과·안 함 뺀 47건 중 이름 있는 것)

**매우 중요 · 긴급 (지금)** — 솔라 아침 한 장 여섯 · 테라 프로필 카드 두 장(217·218) · 레오 감사 대기 13 닫기(부름 두 번 → 마크·빅터·다니엘 → 나리).
**매우 중요 · 보통 (순서대로)** — J2 타임라인 새 판 → 글자 넷 · C17 첨부 셋 · 채팅 여덟(C9·C10·C11·C12·C15·C16 — 11단계 뒤) · 계획 6 책임자·시작·끝·결과물 칸(솔라 다음) · J4 그래프 자료 → J8 그래프 시안(220 뒤) · J7 헨리 "같다" · U1 프로필 열일곱(클레멘타인) · 헨리 목표 한 장 시안.
**보통 중요 · 긴급 (작게 잘라 넘김)** — K6 보드 여덟째 줄기 보이기(11단계 들어오면 저절로) · K2 결재 카드 하나로 · J3 검사기 "- " 줄(하영 표 뒤) · 디자인 감사 대기 셋 Q3·R1·S2(마크 살아 있음 — 부르면 닫힘).
**보통 중요 · 여유 (접수 목록, 회의 때)** — D2 검사기 · D4 위임 감시 · G3 판정 카드 · K5·K7·K8·K9 화면 정리 · K10 이름 하나로 · N3 로밍 기록 · O4(진행이나 여섯이 곧 그것).
**중요하지 않음 · 여유 ("안 함" 후보 — 셋이 동의하면 닫음)** — TL1 타임라인 시안(헨리 새 시안 셋으로 갈음됨) · N2 나리 모델 고르기 카드 · O5 자리별 작업 트리(보류, 대표 한마디감이었으나 218 뒤 두 사람이라 사고가 줄어듦 — 다시 볼 것) · I2 피그마 연동(대표 원문 있음 — 중요하지 않음이 아니라 여유·보통 중요로 옮길지 셋이 봄) · S3 트립튜드 대응표(대표 09-16 원문 있음 — 같은 이유로 셋이 봄).

## 4. 조정 제안 (셋이 동의하면 톰이 보드에)
- 보드에 칸 둘 더함: `importance`(매우·보통·아님) · `urgency`(긴급·보통·여유) — 정본 하나 규칙대로 보드에만, 순서 목록은 거기서 뽑음. 회의 때 바뀐 칸만 고침.
- "안 함" 후보 다섯은 낸 사람(헨리·테라·솔라)에게 한 글자 — 한다/안 함.
- 지금 칸(매우 중요·긴급)은 사람당 하나만 — 테라는 프로필 카드, 솔라는 여섯, 레오 몫은 대신 감사.

## 안 본 것
- 링크 둘은 안 읽음(나래 몫). 마케팅·경영은 나리, 총괄·플랫폼은 나래 표와 합쳐야 전체.
- 47건 중 J·K·C 아닌 잔줄(번호 없는 것)은 표에 안 넣음 — 2판.
