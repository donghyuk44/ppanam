# ppanam

부서별 AI 팀이 **라운드 단위로 일하고 서로 감사하는** 오케스트레이션 시스템.
진행 상황은 **실시간 웹 단톡방**에 말풍선으로 흐른다.

캐스트는 팀마다 3인이다.

| 이름 | 실체 | 역할 |
| --- | --- | --- |
| 길잡이 `guide` | Claude 서브에이전트 | 로드맵을 짜고 스코프를 지키며 실제 작업을 실행 |
| 되짚기 `review` | Claude 서브에이전트 | "이해한 척"을 못 하게 캐묻고 산출물을 감사 |
| 바깥눈 `outside` | 외부 GPT | 다른 모델의 렌즈로 교차검증 |

바깥눈이 다른 회사 모델인 데는 이유가 있다 — **클로드 둘이 사이좋게 같이 틀릴 때
그건 다른 엔진에게만 보이기 때문**이다.

## 돌려보기

```bash
npm install
npm start                 # http://localhost:4321
```

다른 터미널에서:

```bash
node bus/seed.mjs                     # 네 팀에 씨앗 데이터
npm run demo                          # 라운드 한 판이 실시간으로 흐른다
node bus/round.mjs status             # 전체 팀 현황
node bus/say.mjs --as guide "안녕"     # 한 마디
```

폰에서 보려면 Tailscale 같은 VPN으로 이 PC에 붙는다. 배포도 인증도 없다 — 로컬 도구다.

## 화면

- **컴퓨터**: 세 단. 왼쪽은 네 팀의 계기판(진행 중 / 대기 / 대표 호출),
  가운데는 대화, 오른쪽은 상황판(이번 라운드 · 로드맵 · 참여).
- **폰**: 한 단. 팀은 위쪽 가로 띠로 접히고 상황판은 서랍으로 들어간다.

## 세 가지를 섞지 않는다

| | 라운드마다 비우나 |
| --- | --- |
| AI 컨텍스트 | **비운다** — 토큰·속도·성능 |
| 대화록 | **안 비운다** — 카톡처럼 위로 다 나온다 |
| 산출물 | 별개 — `teams/<팀>/out/` |
