# ppanam

부서별 AI 팀이 **라운드 단위로 일하고 서로 감사하는** 오케스트레이션 시스템.
진행 상황은 **실시간 웹 단톡방**에 말풍선으로 흐른다.

캐스트는 팀마다 3인이다.

| 이름 | 실체 | 역할 |
| --- | --- | --- |
| 실무 `guide` | Claude 서브에이전트 | 로드맵을 짜고 스코프를 지키며 실제 작업을 실행 |
| 내부감사 `review` | Claude 서브에이전트 | "이해한 척"을 못 하게 캐묻고 산출물을 감사 |
| 외부감사 `outside` | 외부 GPT | 다른 모델의 렌즈로 교차검증 |

외부감사가 다른 회사 모델인 데는 이유가 있다 — **클로드 둘이 사이좋게 같이 틀릴 때
그건 다른 엔진에게만 보이기 때문**이다.

## 돌려보기

```bash
npm install
npm start                 # http://localhost:4321
```

다른 터미널에서:

```bash
node bus/seed.mjs                     # 네 팀에 씨앗 데이터
npm run demo                          # 라운드 한 판이 실시간으로 흐른다
node bus/round.mjs status             # 전체 팀 현황
node bus/say.mjs --as guide "안녕"     # 한 마디
```

폰에서 보려면 Tailscale 같은 VPN으로 이 PC에 붙는다. 배포도 인증도 없다 — 로컬 도구다.

## 화면

- **컴퓨터**: 세 단. 왼쪽은 네 팀의 계기판(진행 중 / 대기 / 대표 호출),
  가운데는 대화, 오른쪽은 상황판(이번 라운드 · 로드맵 · 참여).
- **폰**: 한 단. 팀은 위쪽 가로 띠로 접히고 상황판은 서랍으로 들어간다.

## 세 가지를 섞지 않는다

| | 라운드마다 비우나 |
| --- | --- |
| AI 컨텍스트 | **비운다** — 토큰·속도·성능 |
| 대화록 | **안 비운다** — 카톡처럼 위로 다 나온다 |
| 산출물 | 별개 — `teams/<팀>/out/` |

## 진행 상황

- **Phase 0** 이벤트 어휘 확정 ✔
- **Phase 1** 채팅방 시안 (`/design` 캔버스) ✔
- **Phase 2** 이벤트 버스 + 실시간 서버 + 3단 화면 ✔
- **Phase 3** 하네스 — 서브에이전트 2인, 슬래시 커맨드 4개, 훅 5종 ✔
  실제 세션에서 훅이 도는 것까지 확인했다 (`bus/say.mjs` 수동 호출 없이 대화록에 쌓인다).
- **Phase 4** 외부감사 어댑터 — codex 연결 확인 ✔ (`codex-cli 0.151.0`, 왕복 9초)
- **Phase 5** 로드맵 엔진 (`/kickoff`) — 코드는 있으나 **아직 한 번도 안 돌렸다**
- **승인 체인** — 등급 A(자동)·B(톰+제리)·C(대표). 대표가 없어도 팀이 달린다 ✔
- **Phase 6** 팀 한 판 완주 — 개발팀이 ppanam 자체를 M2~M6 으로 진행 중

## 외부감사 연결하기

이 자리는 다른 회사 모델이 앉아야 한다. 둘 중 하나면 된다.

```bash
npm run outside -- --setup      # 연결하는 법
npm run outside -- --status     # 지금 무엇이 잡히는지
npm run outside -- --check "2 더하기 2는 5인가?"
```

**codex CLI** (권장 — 저장소 파일을 직접 읽고 판단한다)

```bash
npm install -g @openai/codex
codex login                     # 또는 export CODEX_API_KEY=...
```

**또는 OpenAI API** — `export OPENAI_API_KEY=sk-...` (간단하지만 저장소를 못 읽는다)

연결되면 `--check` 가 실제 답을 돌려준다. 둘 다 없으면 외부감사는 판정하지 않고
"설정 안 됨"이라고 말하고 exit 1 한다.
클로드가 외부감사인 척하면 감사역 셋이 전부 같은 회사 모델이 되어,
**함께 틀리는 지점을 아무도 보지 못한다.**
